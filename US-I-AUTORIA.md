# Ús i autoria

BernatLab és un projecte personal de **Bernat Mora**, compartit públicament per documentar el sistema i facilitar l’aprenentatge.

La publicació del repositori no implica una llicència oberta automàtica. Mentre no s’hi afegeixi una llicència explícita, es mantenen els drets corresponents sobre textos, imatges i artefactes. Les dependències i fonts externes conserven les seves llicències originals.

Per proposar correccions o consultar una reutilització, utilitza el repositori de GitHub.
