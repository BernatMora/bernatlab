Glossari

Termes clau del manual, en ordre alfabètic.

ABP
Activation By Personalization, mètode alternatiu amb claus preconfigurades.
AppEUI
Identificador de l'aplicació LoRaWAN a la qual pertany el node.
AppKey
Clau mestra de 128 bits per autenticar el node durant el join.
BME280
Sensor digital que mesura temperatura, humitat i pressió.
BW
Bandwidth, amplada de banda del canal LoRa.
CayenneLPP
Format de payload eficient per a LoRaWAN, basat en canals i tipus.
Concentratord
Programari per a gateways LoRaWAN basats en SX1302/SX1303.
Debian
Distribució Linux estable i àmpliament utilitzada en servidors.
DevEUI
Identificador únic de 64 bits d'un dispositiu LoRaWAN.
Docker
Plataforma de contenidors que permet empaquetar aplicacions amb les seves dependències.
Docker Compose
Eina per definir i executar múltiples contenidors Docker amb un sol fitxer YAML.
ESP32
Microcontrolador de baix cost amb Wi-Fi i Bluetooth, molt utilitzat en IoT.
ESP32-S3
Variant de l'ESP32 amb més potència i suport per a USB OTG.
Git
Sistema de control de versions distribuït.
Grafana
Plataforma de visualització i alertes per a dades temporals.
HTTPS
HTTP sobre TLS, la versió segura del web.
Homepage
Dashboard modern per a serveis autoallotjats, configurable via YAML.
InfluxDB
Base de dades de sèries temporals optimitzada per a dades amb marca de temps.
LoRa
Tecnologia de ràdio de llarg abast i baix consum (Long Range).
LoRa P2P
Comunicació LoRa directa entre dos dispositius, sense network server.
LoRaWAN
Protocol de xarxa que usa LoRa com a capa física, gestionat per un network server.
MQTT
Protocol de missatgeria lleuger dissenyat per a dispositius IoT.
MagicDNS
Servei DNS de Tailscale que resol noms dins del tailnet.
Mosquitto
Broker MQTT de codi obert, àmpliament utilitzat.
Node-RED
Eina de programació visual basada en fluxos, ideal per a IoT.
OTAA
Over-The-Air Activation, mètode recomanat d'unió a LoRaWAN.
Portainer
Interfície web per gestionar Docker visualment.
RSSI
Indicador de potència del senyal rebut, en dBm.
SF
Spreading Factor. Com més alt, més abast però més lent.
SNR
Relació senyal-soroll, en dB. Indica la qualitat del senyal.
SSH
Protocol segur per accedir a servidors remots.
SX1262
Xip transceiver LoRa de Semtech per a 868/915/923 MHz.
SX1302
Xip concentrador LoRa que pot rebre 8 canals simultàniament.
TLS
Transport Layer Security, protocol de xifrat per a comunicacions.
TTN
The Things Network, network server LoRaWAN comunitari i gratuït.
Tailscale
Xarxa privada basada en WireGuard que permet accedir a dispositius sense obrir ports.
Telegraf
Agent que recull mètriques i les envia a InfluxDB o altres.
Uptime Kuma
Eina de monitoratge autoallotjada amb alertes per Telegram, correu, etc.
Web
Veure World Wide Web (WWW).
branch
Línia de desenvolupament independent en Git.
commit
Instantània dels canvis en un repositori Git.
firewall
Sistema que filtra el tràfic de xarxa segons regles.
merge
Combinar canvis d'una branca a una altra.
pull request
Proposta de canvis per revisar i fusionar en una branca.
reverse proxy
Servidor que rep peticions i les redirigeix a altres servidors.
systemctl
Eina de línia d'ordres per gestionar serveis systemd.
systemd
Sistema d'inicialització i gestió de serveis en Linux modern.
