Resum del capitol

La idea clau

Un microcontrolador es un xip que executa un programa i pot posar tensions de 0 V o 3,3 V a qualsevol dels seus pins (els GPIO). L'ESP32 n'es un dels mes populars perque duu Wi-Fi i Bluetooth integrats, i es pot programar des de qualsevol PC amb un cable USB.

Per que comencem per aqui

Perque es el projecte mes petit possible que tanca el cicle basic:

  • Sabrem flashejar un firmware a l'ESP32.
  • Sabrem fer servir un pin GPIO de sortida.
  • Sabrem connectar l'ESP32 a la xarxa Wi-Fi de casa.
  • Sabrem aixecar un petit servidor web dins del propi xip.
  • Sabrem rebre una ordre HTTP i reaccionar-hi canviant l'estat d'un pin.

Que es un microcontrolador (en 30 segons)

Un microcontrolador es un ordinador molt petit, en un sol xip, que te:

  • Un processador (cervell que executa instruccions).
  • Una memoria per al programa i les dades.
  • Uns pins d'entrada/sortida (GPIO) que podem posar a 0 V o 3,3 V.
  • Algunes interficies de comunicacio: UART, I2C, SPI, i a vegades Wi-Fi, Bluetooth, USB.

Que necessitem

  • ESP32 DevKit v1 (xip ESP32-WROOM-32) - 1 unitat
  • LED 5 mm - 1 unitat
  • Resistencia 220 ohm (o 330 ohm) - 1 unitat
  • Cable USB micro-B - 1 unitat
  • Protoboard i cables Dupont - 1 + 3
  • PC amb Arduino IDE o PlatformIO

Connexions

ESP32                    Protoboard
+-----------+
|           |      LED + R 220 ohm
|       GND +------+[ 220 ohm ]--+
|           |                    |
|     GPIO 2+--------------------+ (costat llarg del LED, anode)
|           |                    (costat curt del LED, catode, al GND)
+-----------+

Per que GPIO2 i no un altre?

Per defecte, moltes DevKit v1 ja duen un LED soldat a GPIO2. Es una eleccio segura perque esta documentat, es pot fer servir el LED de la placa sense soldar res, i esta lluny dels pins de la memoria flash.

Important: mai connectis res als pins GPIO6, GPIO7, GPIO8, GPIO9, GPIO10, GPIO11. Estan lligats a la memoria flash interna de l'ESP32.

Codi minim (tot el projecte)

#include <WiFi.h>
#include <WebServer.h>

const char* ssid     = "EL_TEU_WIFI";
const char* password = "LA_TEUA_CONTRASENYA";

const int LED_PIN = 2;
WebServer servidor(80);

void handle_root() {
  String html = R"(
    <!doctype html>
    <html><head><meta charset='utf-8'>
    <title>Bernat Maker Lab - P0</title>
    <style>
      body { font-family: system-ui; max-width: 480px; margin: 40px auto; text-align: center; }
      a.btn { display: inline-block; padding: 12px 24px; margin: 8px;
              background: #0a84ff; color: white; text-decoration: none; border-radius: 8px; }
      a.off { background: #555; }
    </style></head><body>
      <h1>Bernat Maker Lab</h1>
      <h2>Projecte P0 - LED via web</h2>
      <p><a class='btn' href='/on'>ON</a>
         <a class='btn off' href='/off'>OFF</a></p>
    </body></html>
  )";
  servidor.send(200, "text/html", html);
}

void handle_on()  { digitalWrite(LED_PIN, HIGH); handle_root(); }
void handle_off() { digitalWrite(LED_PIN, LOW);  handle_root(); }

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);

  WiFi.begin(ssid, password);
  Serial.print("Connectant a Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println();
  Serial.print("ESP32 connectat. Obre: http://");
  Serial.println(WiFi.localIP());

  servidor.on("/",  handle_root);
  servidor.on("/on",  handle_on);
  servidor.on("/off", handle_off);
  servidor.begin();
}

void loop() {
  servidor.handleClient();
}

Exercici practic (60-90 min)

Muntar, programar i fer funcionar el projecte P0 del Bernat Maker Lab: una ESP32 que encen i apaga un LED des d'una pagina web oberta al navegador. Verificar que tota la cadena funciona (Wi-Fi -> ESP32 -> LED) abans de passar a P1.

Pas 1: Instal·la Arduino IDE (10 min)

  1. Descarrega Arduino IDE 2.x des de la web oficial.
  2. Instal·la'l amb les opcions per defecte.
  3. Obre'l. Ves a File -> Preferences.
  4. Al quadre "Additional boards manager URLs", enganxa la URL del paquet esp32 d'Espressif.
  5. Ves a Tools -> Board -> Boards Manager i instal·la el paquet esp32.

Pas 2: Connecta l'ESP32 i instal·la el driver (5 min)

Connecta l'ESP32 al PC amb el cable USB. A Windows, obre el Device Manager. Si no apareix cap port COM, instal·la el driver CH340 (si la teva placa en duu).

Pas 3: Munta el circuit (5 min)

Seguint l'esquema del resum, munta el LED i la resistencia a la protoboard. Desconnecta sempre l'ESP32 del PC abans de fer canvis al circuit.

Pas 4: Escriu i puja el codi (10 min)

Enganxa el codi del resum, canvia les credencials Wi-Fi, selecciona "ESP32 Dev Module" a Tools, selecciona el port COM correcte, i puja'l.

Pas 5: Verifica que tot funciona (5 min)

Obre el Serial Monitor a 115200 baud, apunta't la IP, obre-la al navegador, prem els botons. El LED s'ha d'encendre i apagar.

Validacio

Has acabat si:

  • Has vist "ESP32 connectat" al Serial Monitor.
  • Has pogut obrir la pagina web a la IP de l'ESP32.
  • El LED sencen i sapaga en premar els botons.
  • Has provat el Blink classic per separat i funciona.
  • Has fet una captura de pantalla de la pagina web funcionant.

Respostes

Les respostes completes amb explicacions estan al fitxer respostes.md del repositori.

Resum rapid

  1. Microcontrolador = xip amb processador, memoria i GPIO, que executa un sol programa.
  2. GPIO = pin configurable com a entrada o sortida digital.
  3. 3,3 V = la tensio dels GPIO de l'ESP32 (mai 5 V!).
  4. Limitar el corrent = per no cremar el LED ni forcar el pin.
  5. GPIO6-11 = prohibits, lligats a la memoria flash.
  6. Iniciar la connexio = a la xarxa Wi-Fi indicada.
  7. L'adreca IP = assignada pel router via DHCP.
  8. 80 = port per defecte d'HTTP.
  9. Verdader = l'ESP32 es el servidor web.
  10. S'encen el LED = la ruta /on posa el pin a HIGH.
  11. DHCP = assigna IPs dinamiques que poden canviar.
  12. MQTT = millor per sensors (menys energia, mes flexible).
  13. Arduino IDE = la millor eina per començar.
  14. Caracters estranys = velocitat del monitor mal posada.
  15. 5-7 EUR = cost aproximat d'una ESP32 DevKit v1.
