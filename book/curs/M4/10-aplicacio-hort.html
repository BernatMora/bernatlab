📖 Resum del capitol

La idea clau

Aquest ultim capitol del modul aplica tot el que hem vist al cas real del projecte Hort Osona: un sistema de consulta a la base de coneixement de l'hort amb IA local, 100% privat.

El sistema complet

Ara que tens Ollama, embeddings, ChromaDB, i el pipeline RAG, pots muntar el teu propi assistent horticola que coneix les 76 fitxes de cultiu d'Hort Osona, coneix el calendari de sembra, plagues, associacions, respon preguntes en catala, i es queda al teu servidor - res surt de casa.

Pas 1: Preparar la base de coneixement

Tots els fitxers d'Hort Osona son a https://github.com/BernatMora/hort-osona/. Cal clonar-lo:

cd /home/bernat
git clone https://github.com/BernatMora/hort-osona.git

Ara tens 80+ documents en catala sobre horticultura.

Pas 2: Indexar els documents

Crea un script indexar_hort.py amb chromadb.PersistentClient, get_embedding que crida Ollama, i chunk_text que divideix en fragments de 500 paraules amb overlap de 50. Recorre tots els .md amb Path.rglob i els indexa amb metadades de la font.

Pas 3: Crear l'API de consulta

Crea consultar_hort.py amb la funcio ask_hort(question, k=5) que: (1) busca els 5 fragments mes rellevants, (2) prepara un prompt amb contexte que ordena al LLM respondre nomes en catala amb la informacio donada, (3) envia a Ollama llama3.2, i (4) retorna la resposta amb les fonts.

Pas 4: Integrar amb Open WebUI (opcional)

Si tens Open WebUI instal·lat, pots connectar-hi el RAG. A Open WebUI ves a Settings > Connections, afegeix una nova OpenAI API connection amb URL http://localhost:11434/v1 i model llama3.2. Ara pots xatejar amb el LLM directament des d'Open WebUI. Per al RAG, cal una extensio (potser mes complex).

Proves que pots fer

Un cop tot funcioni, prova:

  • "Com es planta el tomàquet a Osona?"
  • "Quines plagues pateix l'enciam al juliol?"
  • "Quan s'ha de sembrar la carbassa?"
  • "Quines plantes son bones companyes de la mongeta?"

Si tot va be, el sistema et respondra amb informacio especifica d'Hort Osona, no pas informacio generica.

Limitacions

  • Qualitat dels embeddings depen del model. nomic-embed-text es bo pero no perfecte.
  • Qualitat del LLM depen del model. llama3.2 es bo, pero mistral o gemma poden ser millors per a catala.
  • Velocitat depen del hardware. La RPi es lenta per a models grans.
  • Cobertura depen dels documents indexats. Si un tema no es a Hort Osona, no es pot respondre.

🛠️ Exercici practic (45-60 min)

Muntar el sistema Hort Osona complet: clonar el repo, indexar els 80+ documents i respondre preguntes reals.

Pas 1: Clonar Hort Osona (5 min)

cd ~
git clone https://github.com/BernatMora/hort-osona.git
cd hort-osona
find . -name "*.md" | wc -l

Pas 2: Script d'indexacio (15 min)

Crea indexar_hort.py amb chromadb.PersistentClient, get_embedding (Ollama) i chunk_text (500/50). Recorre tots els .md amb rglob, genera embeddings i guarda amb metadades de la font.

Pas 3: Script de consulta (15 min)

Crea consultar_hort.py amb la funcio ask_hort(question, k=5): embedding, cerca, prompt, generacio, fonts. Afegeix un bucle interactiu amb input().

Pas 4: Proves reals (15 min)

Prova les 4 preguntes suggerides. Comprova que les respostes son especifiques d'Hort Osona i que les fonts son els fitxers correctes.

Validacio

  • ☐ Repo d'Hort Osona clonat.
  • ☐ Indexacio ha acabat amb exit.
  • ☐ El script de consulta funciona.
  • ☐ Les respostes inclouen informacio especifica.
  • ☐ He provat almenys 4 preguntes diferents.

✅ Respostes

Les respostes completes amb explicacions estan al fitxer respostes.md del repositori.
