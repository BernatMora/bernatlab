📖 Resum del capitol

La idea clau

Ollama es un programa que et permet tenir LLMs funcionant al teu servidor amb quatre comandes. Es el "Docker dels models": descarregues, executes, i tens un API REST llest per cridar. I esta fet en Go, es rapidissim, i funciona igual a Mac, Linux, Windows i Raspberry Pi.

Que es Ollama exactament?

Ollama es un runtime per a LLMs. Pensa-ho com el dockerd del mon dels models: una vegada l'instales, pots fer:

  • ollama pull llama3.2 - descarrega un model.
  • ollama run llama3.2 - xateja amb el model per terminal.
  • ollama serve - exposa un API REST al port 11434.

Aquest API REST es la part clau per al BernatLab: podem cridar el LLM des de qualsevol script Python, Node, o shell sense reinventar la roda.

Instal·lacio a la Raspberry Pi 4

A Debian 13 (arm64), la instal·lacio es tan simple com:

curl -fsSL https://ollama.com/install.sh | sh

Aixo:

  1. Descarrega el binari d'Ollama optimitzat per arm64.
  2. Crea un usuari de sistema ollama.
  3. Activa un servei systemd (ollama.service).
  4. Configura el directori /usr/share/ollama/.ollama per guardar els models.

Verifica la instal·lacio:

ollama --version
systemctl status ollama

Els primers models

Ollama ve amb un cataleg de models al seu registre. Els mes interessants per a la RPi 4 son:

  • llama3.2:1b: 1.3 GB de descarrega, ~1 GB de RAM en executar.
  • llama3.2:3b: 2.0 GB de descarrega, ~2.5 GB de RAM.
  • phi3:mini: 2.3 GB, optimitzat per a raonament.
  • gemma2:2b: 1.6 GB, alternativa de Google.

Com descarregar-los:

ollama pull llama3.2:1b
ollama pull llama3.2:3b

Xatejar per terminal

La forma mes rapida de provar-ho:

ollama run llama3.2:1b

Ara escriu el que vulguis. Per sortir, escriu /bye.

L'API REST: la part interessant

El servei esta actiu, pots cridar el LLM des de qualsevol lloc:

curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2:1b",
  "prompt": "Quina es la capital de Catalunya?",
  "stream": false
}'

Tambe te un endpoint de xat (mes convenient per a converses):

curl http://localhost:11434/api/chat -d '{
  "model": "llama3.2:1b",
  "messages": [
    {"role": "user", "content": "Hola, qui ets?"}
  ],
  "stream": false
}'

I un endpoint d'embeddings (que veurem al cap. 6):

curl http://localhost:11434/api/embeddings -d '{
  "model": "llama3.2:1b",
  "prompt": "Hola mon"
}'

Estructura de directoris

Ollama desa els models a:

  • Models descarregats: /usr/share/ollama/.ollama/models/ (a Linux).
  • Configuracio del servei: /etc/systemd/system/ollama.service.
  • Logs: journalctl -u ollama.

Atencio: aquests fitxers son grans. Un model de 7B ocupa uns 4-8 GB.

Configuracio basica del servei

Pots ajustar el comportament d'Ollama editant el servei systemd:

sudo systemctl edit ollama

Afegeix, per exemple:

[Service]
Environment="OLLAMA_HOST=0.0.0.0:11434"
Environment="OLLAMA_MODELS=/mnt/dades/ollama-models"
Environment="OLLAMA_KEEP_ALIVE=10m"

Aixo fa que escolti a totes les interficies, guardi els models a un disc de dades, i mantingui el model carregat 10 min despres de la ultima consulta.

Comandes essentials

  • ollama --version - Versio instal·lada
  • ollama list - Models descarregats
  • ollama pull MODEL - Descarregar un model
  • ollama run MODEL - Xatejar per terminal
  • ollama rm MODEL - Esborrar un model
  • ollama ps - Models carregats a memoria
  • ollama show MODEL - Info detallada d'un model
  • ollama serve - Engegar el servidor API

🛠️ Exercici practic (30-45 min)

Instal·lar Ollama a la teva Raspberry Pi 4 (o maquina virtual Linux), descarregar el teu primer model, i fer una consulta tant per terminal com per API REST.

Pas 1: Instal·la Ollama (5 min)

curl -fsSL https://ollama.com/install.sh | sh
ollama --version
systemctl status ollama

Pas 2: Mou el directori de models (opcional) (5 min)

sudo systemctl edit ollama

Afegeix:

[Service]
Environment="OLLAMA_MODELS=/mnt/dades/ollama-models"
sudo systemctl daemon-reload
sudo systemctl restart ollama

Pas 3: Descarrega el teu primer model (5-10 min)

ollama pull llama3.2:1b
ollama pull llama3.2:3b
ollama list

Pas 4: Xateja per terminal (5 min)

ollama run llama3.2:1b

Prova: Hola, qui ets?, Explica'm que es una Raspberry Pi en 3 frases, Escriu un script bash que compti els fitxers d'un directori. Per sortir: /bye.

Pas 5: Crida l'API REST (10 min)

curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2:1b",
  "prompt": "Quants dies te un any de traspas?",
  "stream": false
}'

curl http://localhost:11434/api/chat -d '{
  "model": "llama3.2:1b",
  "messages": [
    {"role": "user", "content": "Resum en una frase que es Docker."}
  ],
  "stream": false
}'

curl http://localhost:11434/api/tags
curl http://localhost:11434/api/ps

Pas 6: Documenta la teva experiencia (10 min)

Crea book/curs/M4/02-ollama-instalacio/primera-consulta.md amb versio d'Ollama, models descarregats, temps de resposta, valoracio subjectiva.

Validacio

  • ☐ Ollama esta instal·lat i el servei esta active (running).
  • ☐ Has descarregat almenys un model.
  • ☐ Has xatejat amb el model per terminal.
  • ☐ Has fet una crida a l'API REST amb curl.
  • ☐ Has documentat la teva experiencia a primera-consulta.md.
