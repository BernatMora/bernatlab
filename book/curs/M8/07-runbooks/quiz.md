# Quiz - M8 Cap 7: Runbooks

## Pregunta 1
Que es un runbook?

- [ ] Un llibre de lectura
- [x] Un document amb procediments per a situacions especifiques
- [ ] Un sistema operatiu
- [ ] Un tipus de base de dades

## Pregunta 2
Quina es la primera seccio dun runbook?

- [ ] Solucio
- [x] Símptomes
- [ ] Validacio
- [ ] Notes

## Pregunta 3
Quan sha descriure un runbook?

- [ ] Quan tinguis temps lliure
- [x] Quan resols un problema, immediatament
- [ ] Un cop l'any
- [ ] Mai

## Pregunta 4
On NO hauries de guardar runbooks?

- [ ] Al repo del projecte
- [ ] A Obsidian
- [x] Al servidor que pot fallar (com a unica copia)
- [ ] Al núvol privat

## Pregunta 5
Quantes seccions ha de tenir un runbook?

- [ ] 1
- [ ] 3
- [x] 5-6 (símptomes, diagnòstic, solució, validació, notes)
- [ ] 10+

## Pregunta 6
Que sha dincloure en un runbook a mes de la solucio?

- [ ] La teva opinio personal
- [x] Comandes exactes, casos especials, errors comuns
- [ ] Link a Amazon
- [ ] Receptes de cuina

## Pregunta 7 (oberta)
Per que els runbooks son importants a un homelab?

Pistes:
- Quan algo falla
- Quan no estas a casa
- Quan oblides com es fa
- Quan algú altre ha de mantenir el sistema

## Pregunta 8 (oberta)
Explica quan sha descriure un runbook i quan sha d'actualitzar.

Pistes:
- Immediatament despres de resoldre
- Quan canvia el sistema
- Periode de revisio
- Casos nous

## Pregunta 9 (oberta)
Quins runbooks essencials hauries de tenir?

Pistes:
- Els problemes mes comuns
- Els mes critics
- Els que tens por que passin
- Llista minima viable

## Pregunta 10 (oberta)
Per que es important tenir una copia dels runbooks FORA del servidor?

Pistes:
- Que passa si el servidor cau
- Que passa si no pots accedir
- Que passa si la informacio es perd
- Pla B
