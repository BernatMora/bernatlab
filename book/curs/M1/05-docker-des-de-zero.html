📖 Resum del capítol

La idea clau

Docker és l'eina que fa possible el BernatLab. Cada servei corre dins d'un contenidor: una capsa aïllada amb el programa i les seves dependències. Es pot aixecar, parar, moure o esborrar en segons.

Què és un contenidor?

Pensa en un contenidor com un apartament dins d'un edifici. L'edifici és el sistema operatiu (Debian 13). Cada apartament té el seu sistema de fitxers, xarxa, processos, CPU/RAM. Comparteixen el kernel però estan aïllats.

Imatges vs contenidors

  • Imatge = plantilla de només lectura (la "receta").
  • Contenidor = instància viva d'una imatge (el "pis").
docker pull nginx:1.27-alpine
docker images
docker run -d --name web -p 8080:80 nginx:1.27-alpine

Comandes bàsiques

docker ps                 # contenidors actius
docker ps -a              # tots els contenidors
docker logs web           # veure logs
docker logs -f web        # seguir logs en temps real
docker stop web           # aturar
docker start web          # arrencar
docker restart web        # reiniciar
docker rm -f web          # esborrar forçat
docker stats              # CPU/RAM en temps real
docker exec -it web sh    # entrar dins el contenidor

Volums: persistència

Quan esborres un contenidor, es perden les dades. Per persistir-les, usem volums:

# Volum nombrat (Docker el gestiona)
docker volume create dades-portainer
docker run -d -p 9000:9000 -v dades-portainer:/data portainer/portainer-ce

# Bind mount (carpeta del host)
docker run -d -p 8080:80 -v /home/bernat/web:/usr/share/nginx/html nginx

Xarxes Docker

docker network create homelab
docker run -d --network homelab --name db postgres:16
docker run -d --network homelab --name portainer -p 9000:9000 portainer/portainer-ce
# portainer pot accedir a "db" pel nom

Docker Compose: el tot-en-un

# ~/homelab/docker/docker-compose.yml
version: "3.9"

services:
  portainer:
    image: portainer/portainer-ce:latest
    container_name: portainer
    ports:
      - "9000:9000"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - portainer_data:/data
    restart: unless-stopped

  uptime:
    image: louislam/uptime-kuma:latest
    container_name: uptime-kuma
    ports:
      - "3001:3001"
    volumes:
      - uptime_data:/app/data
    restart: unless-stopped

volumes:
  portainer_data:
  uptime_data:
cd ~/homelab/docker
docker compose up -d          # aixeca tot
docker compose down           # para i esborra
docker compose ps             # estat
docker compose logs -f        # logs agregats
docker compose pull           # actualitza imatges
docker compose up -d          # aplica canvis

Bones pràctiques

  1. Un servei per contenidor.
  2. Imatges Alpine quan sigui possible (5-10x més petites).
  3. Volums per a dades: mai confiïs en el FS del contenidor.
  4. restart: unless-stopped perquè els serveis tornin sols.
  5. Etiqueta amb versions: nginx:1.27-alpine en lloc de nginx:latest.
  6. Fes servir Compose: un sol fitxer per a tot l'homelab.

🛠️ Exercici pràctic (40-60 min)

Instal·lar Docker, practicar ordres bàsiques i muntar el primer docker-compose.yml.

Pas 1: Instal·la Docker (10 min)

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker bernat
newgrp docker
docker --version
docker compose version
docker run hello-world

Pas 2: Primera experiència (10 min)

docker run -d --name prova-nginx -p 8080:80 nginx:alpine
docker ps
curl http://localhost:8080
docker exec -it prova-nginx sh
ls /usr/share/nginx/html/
exit
docker logs prova-nginx
docker logs -f prova-nginx
docker stop prova-nginx
docker rm prova-nginx

Pas 3: Volums (10 min)

docker volume create dades-prova
docker run -d --name writer -v dades-prova:/dades alpine sh -c "while true; do date >> /dades/log.txt; sleep 5; done"
docker exec writer cat /dades/log.txt
sleep 15
docker exec writer cat /dades/log.txt
docker stop writer
docker rm writer
docker run --rm -v dades-prova:/dades alpine cat /dades/log.txt

Pas 4: Xarxes (10 min)

docker network create homelab-xarxa
docker run -d --name db --network homelab-xarxa -e POSTGRES_PASSWORD=secret postgres:16-alpine
docker run -d --name web --network homelab-xarxa -p 8081:80 nginx:alpine
docker exec web ping -c 2 db
docker stop db web
docker rm db web
docker network rm homelab-xarxa

Pas 5: Primer docker-compose.yml (15 min)

Crea ~/homelab/docker/docker-compose.yml:

version: "3.9"

services:
  whoami:
    image: traefik/whoami
    container_name: whoami
    ports:
      - "8080:80"
    restart: unless-stopped

  portainer:
    image: portainer/portainer-ce:latest
    container_name: portainer
    ports:
      - "9000:9000"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - portainer_data:/data
    restart: unless-stopped

volumes:
  portainer_data:
cd ~/homelab/docker
docker compose up -d
docker compose ps
curl http://localhost:8080
docker compose logs -f

Pas 6: Neteja i documenta

cd ~/homelab/docker
docker compose down

Resum ràpid

  1. Imatge = plantilla; contenidor = instància viva.
  2. docker run -d = executar en segon pla.
  3. Volum = persistir dades més enllà del contenidor.
  4. Compose = docker-compose.yml.
  5. docker compose up -d = aixecar serveis en background.
  6. Alpine = 5-10x més petita.
  7. docker ps -a = tots els contenidors.
  8. restart: unless-stopped = recomanada.
