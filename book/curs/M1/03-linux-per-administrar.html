📖 Resum del capítol

La idea clau

Un cop tens la Raspberry Pi en marxa amb Debian 13 Lite, toca aprendre a parlar amb ella. Ordres de terminal, gestió d'usuaris, instal·lació de programari, logs i serveis. Són les ordres bàsiques que faràs servir cada dia al BernatLab (hostname hortosona, IP Tailscale 100.115.134.76).

El sistema de fitxers

/home/bernat/homelab/    <-- el teu homelab (on viurà tot)
/etc/                     <-- configuració del sistema
/var/log/                 <-- logs (registres d'activitat)
/usr/bin/                 <-- programes instal·lats
/proc/                    <-- informació del sistema i processos

Les carpetes clau: /home/bernat/ (la teva home), /etc/ (configuració), /var/log/ (logs), /opt/ (programes manuals).

Navegació i gestió de fitxers

pwd                       # On soc?
ls -lah                   # Què hi ha aquí?
cd /home/bernat/homelab   # Canvia de carpeta
mkdir docker              # Crea carpeta
touch notes.md            # Crea fitxer buit
cp fitxer.txt copia.txt   # Copia
mv fitxer.txt nou.txt     # Mou o reanomena
rm fitxer.txt             # Esborra (compte, no hi ha paperera!)

cd sense arguments et porta a /home/bernat/. cd .. puja un nivell. cd - torna a l'anterior.

Usuaris, grups i permisos

Cada fitxer té un propietari (usuari), un grup, i tres permisos: llegir (r), escriure (w), executar (x).

ls -l notes.md
# -rw-r--r-- 1 bernat bernat 1234 nov 12 10:30 notes.md
# ^^^^^^^^^  ^^^^^^  ^^^^^^
# permisos  usuari   grup

La cadena -rw-r--r-- es llegeix: tipus (-) + permissos del propietari (rw-) + del grup (r--) + d'altres (r--).

chmod 755 script.sh       # rwxr-xr-x
chmod 644 fitxer.txt      # rw-r--r-- (estàndard per a fitxers)
chmod +x script.sh        # afegeix execució
sudo chown bernat:bernat fitxer.txt

sudo: fer coses d'administrador

sudo apt update                    # actualitza la llista de paquets
sudo systemctl restart ssh         # reinicia el servei SSH
sudo nano /etc/hosts                # edita un fitxer del sistema

La primera vegada et demana la contrasenya. Durant 15 minuts no te la torna a demanar. Compte: un sudo rm -rf / esborraria TOT el sistema.

Gestió de paquets amb apt

sudo apt update              # descarrega la llista de paquets
sudo apt upgrade             # instal·la les actualitzacions
sudo apt install htop        # instal·la un programa
sudo apt remove htop         # desinstal·la
apt search "monitor"         # busca paquets

Sempre sudo apt update abans d'instal·lar, i sudo apt upgrade un cop al mes.

L'editor nano

nano /etc/hosts       # obre l'editor

Dins de nano: Ctrl+O guarda, Ctrl+X surt, Ctrl+K talla, Ctrl+W busca, Ctrl+C cancel·la.

Serveis amb systemd

sudo systemctl status ssh        # estat
sudo systemctl start ssh         # arrenca
sudo systemctl stop ssh          # para
sudo systemctl restart ssh       # reinicia
sudo systemctl enable ssh        # arrenca automàticament en boot
systemctl list-units --type=service --state=running

Logs bàsics

sudo journalctl -u ssh --since today    # logs d'un servei
sudo journalctl -u ssh -f               # tail -f amb journalctl
sudo journalctl -p err -b               # errors des de l'últim boot
tail -f /var/log/syslog                 # log general clàssic
tail -f /var/log/auth.log               # autenticacions

🛠️ Exercici pràctic (30-45 min)

Practicar les ordres bàsiques de Linux al BernatLab: navegar, crear fitxers, permisos, instal·lar programari, mirar logs.

Pas 1: Navega i crea estructura (10 min)

cd ~
mkdir -p homelab/{docker,config,notes,scripts,logs}
ls -la homelab/
tree homelab/ 2>/dev/null || find homelab/ -type d
cd homelab
echo "# El meu homelab" > README.md
cat README.md

Pas 2: Permisos (10 min)

cd ~/homelab/scripts
nano hola.sh
# Escriu:
#!/bin/bash
echo "Hola des del BernatLab!"
# Ctrl+O per guardar, Ctrl+X per sortir

ls -l hola.sh
chmod +x hola.sh
ls -l hola.sh
./hola.sh

touch secret.txt
chmod 600 secret.txt
ls -l secret.txt

Pas 3: Instal·la eines amb apt (10 min)

sudo apt update
sudo apt install -y htop tree ncdu
htop --version
tree --version
ncdu --version
htop
tree ~/homelab -L 2
ncdu ~/homelab

Pas 4: Gestió de serveis (10 min)

systemctl list-units --type=service --state=running | head -20
sudo systemctl status ssh
sudo journalctl -u ssh --since "1 hour ago" | tail -20
sudo journalctl -u ssh -f

Pas 5: Documenta

Crea book/curs/M1/03-linux-per-administrar/diari.md amb les ordres que més has fet servir i notes personals.

Validació

  • ☐ Has creat l'estructura homelab/{docker,config,notes,scripts,logs}.
  • ☐ Has fet executable un script amb chmod +x i l'has executat.
  • ☐ Has canviat permisos a 600 i has comprovat la diferència.
