📖 Resum del capítol

La idea clau

Uptime Kuma és el "quadre de comandament" del BernatLab: vigila si els teus serveis estan vius, mesura el temps de resposta, i t'avisa per Telegram quan algo cau. S'hi accedeix via http://hortosona:3001.

Què és Uptime Kuma?

Aplicació web self-hosted per monitorar serveis. Tipus de monitors: HTTP(s), Ping, TCP port, DNS, Docker Container, Push, SQL/Mongo/Redis/Postgres, certificat SSL, i més.

Per què l'usem

  • Saber ràpid si algo ha caigut (sense esperar que ho noti un visitant).
  • Mesurar uptime (% de temps actiu).
  • Detectar degradació (latència creixent).
  • Rebre alertes al mòbil (Telegram).
  • Visualitzar tendències (gràfiques).
  • Pàgina pública d'estat.

Instal·lació

services:
  uptime-kuma:
    image: louislam/uptime-kuma:latest
    container_name: uptime-kuma
    ports:
      - "3001:3001"
    volumes:
      - uptime_data:/app/data
      - /var/run/docker.sock:/var/run/docker.sock
    restart: unless-stopped

volumes:
  uptime_data:

Primers monitors

  1. RPi ping: Ping a 127.0.0.1, 60s.
  2. Portainer: HTTP a http://localhost:9000, 60s.
  3. Internet: HTTP a https://1.1.1.1, 5 min.
  4. SSH: TCP port 22, 60s.
  5. Homepage (quan el tinguis): HTTP a http://localhost:3010.

Alertes: Telegram

  1. Parla amb @BotFather a Telegram.
  2. Envia /newbot, posa nom + username.
  3. Guarda el token.
  4. Inicia conversa amb el bot.
  5. Obté el chat_id amb https://api.telegram.org/bot<TOKEN>/getUpdates.
  6. A Uptime Kuma: Settings > Notifications > Telegram.
  7. Test, desa.

Altres canals

Email, Discord, Slack, Teams, Pushover, Gotify, Webhook genèric. Al BernatLab: Telegram + Email de backup.

Status Page

Status Pages > New > nom + slug + monitors. URL: http://hortosona:3001/status/<slug>. Pública per compartir amb família/amics.

Correlació amb Portainer

  • Portainer: operacions manuals + visualització.
  • Uptime Kuma: vigilància passiva + alertes.

🛠️ Exercici pràctic (45-60 min)

Posar en marxa Uptime Kuma, configurar monitors, alertes Telegram i Status Page.

Pas 1: Afegeix al compose (10 min)

Edita ~/homelab/docker/docker-compose.yml amb Uptime Kuma, Portainer i whoami. Fes docker compose up -d.

Pas 2: Configuració inicial (5 min)

Obre http://hortosona:3001, crea admin.

Pas 3: Crea 5 monitors (15 min)

  • RPi ping a 127.0.0.1.
  • Portainer HTTP a http://localhost:9000.
  • Whoami HTTP a http://localhost:8080.
  • SSH TCP port 22.
  • Internet HTTPS a https://1.1.1.1.

Pas 4: Crea el bot de Telegram (10 min)

@BotFather > /newbot > nom + username > token. Inicia conversa. Obté chat_id amb getUpdates.

Pas 5: Configura alerta (10 min)

Settings > Notifications > Telegram > token + chat_id > Test > Save.

Pas 6: Connecta alertes als monitors (5 min)

Edita cada monitor, afegeix notificació Telegram amb "When down" + "When up".

Pas 7: Prova (10 min)

docker stop whoami, espera 60-180s, comprova alerta al mòbil. docker start whoami, comprova "UP".

Pas 8: Status Page (5 min)

Status Pages > New > slug bernatlab > afegeix tots els monitors.

Validació

  • ☐ Uptime Kuma corre a http://hortosona:3001.
  • ☐ Tens almenys 5 monitors actius.
  • ☐ Bot de Telegram creat amb token + chat_id.
  • ☐ Alerta de Telegram configurada i provada.
  • ☐ Status Page pública.
  • ☐ Has documentat a diari.md.
