📖 Resum del capítol

La idea clau

Portainer és una interfície gràfica web per administrar Docker. Veure contenidors, logs, volums, imatges, xarxes i fer operacions amb clics. Al BernatLab s'hi accedeix via http://hortosona:9000 (o http://100.115.134.76:9000 des de fora amb Tailscale).

Què és exactament Portainer?

Un contenidor Docker que administra altres contenidors. Comunica amb el dimoni Docker a través del socket /var/run/docker.sock. Versió Community (gratuïta) i Business (de pagament).

Per què l'usem al BernatLab?

  • Visibilitat: veure d'un cop d'ull tots els contenidors, el seu estat, CPU, RAM.
  • Logs centralitzats: sense fer docker logs.
  • Control: arrencar, parar, reiniciar, recrear amb botons.
  • Editor de Compose: editar docker-compose.yml al navegador.
  • Stack: gestionar múltiples serveis com una unitat.
  • Consola web: entrar dins un contenidor amb un terminal al navegador.

Instal·lació

services:
  portainer:
    image: portainer/portainer-ce:latest
    container_name: portainer
    ports:
      - "9000:9000"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - portainer_data:/data
    restart: unless-stopped

volumes:
  portainer_data:
cd ~/homelab/docker
docker compose up -d portainer

Primer accés

  1. Obre el navegador a http://hortosona:9000.
  2. Crea l'usuari administrador (contrasenya forta).
  3. Tria "Local" per administrar el Docker de la RPi.
  4. Ja ets al tauler principal.

El tauler

Seccions principals: Stacks, Containers, Images, Networks, Volumes.

Gestió de contenidors

  • Estat (running, stopped, paused).
  • Mètriques en temps real (CPU%, RAM MB, xarxa).
  • Start / Stop / Restart / Kill.
  • Logs amb cerca i filtres.
  • Consola (shell dins del contenidor).
  • Detalls: env, volums, xarxes, ports.
  • Recrear / Esborrar.

Editor de Stacks (Compose)

Stacks > Add stack > Web editor > enganxa el YAML > Deploy. Equivalent a fer docker compose up -d.

Alerta: al BernatLab, tot el compose viu al sistema de fitxers. Només usem Portainer per visualitzar/operar, no per crear stacks nous.

Volums i xarxes

Secció "Volumes": veure mida, navegar contingut, esborrar (amb cura). Secció "Networks": veure quins contenidors estan connectats, però poques vegades tocarem res.

Limites i advertències

  • Una sola màquina per instància Local (per a múltiples, cal Business o Agent).
  • No substitueix la terminal per a operacions avançades.
  • HTTP per defecte: acceptable via Tailscale, però a Internet caldria HTTPS.

🛠️ Exercici pràctic (30-45 min)

Posar en marxa Portainer, accedir-hi, i practicar les operacions bàsiques d'administració.

Pas 1: Afegeix Portainer al compose (10 min)

Edita ~/homelab/docker/docker-compose.yml amb el snippet de Portainer i whoami. Fes docker compose up -d.

Pas 2: Primer accés (10 min)

  1. Obre http://hortosona:9000.
  2. Crea l'usuari admin (contrasenya forta).
  3. Tria "Get Started" (entorn Local).
  4. Explora el Dashboard.

Pas 3: Explora els contenidors (10 min)

Vés a "Containers" > whoami > pestanyes Logs, Stats, Console. Fes curl http://hortosona:8080 i mira els logs.

Pas 4: Aturar i reiniciar (5 min)

Stop whoami a Portainer, comprova amb docker ps -a per SSH, torna a Start.

Pas 5: Volums (5 min)

Secció "Volumes" > portainer_data > Browse.

Pas 6: Stack des de Portainer (opcional, 10 min)

Stacks > Add stack > prova-stack > Web editor amb nginx > Deploy. Comprova a http://hortosona:8082.

Pas 7: Neteja i documenta

Esborra el stack de prova. Documenta a book/curs/M1/06-portainer/diari.md.
