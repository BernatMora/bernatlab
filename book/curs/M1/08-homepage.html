📖 Resum del capítol

La idea clau

Homepage és un dashboard self-hosted que centralitza tots els serveis del BernatLab en una sola pàgina. Porta d'entrada via http://hortosona:3010.

Què és exactament?

Aplicació web Next.js (React). Graella de targetes per servei, amb dades en temps real (latència, estat, pings, temperatures).

Per què l'usem

  • Punt d'entrada únic.
  • Visió ràpida de tot.
  • Personalitzable.
  • Compartible selectivament.
  • Autoexplicatiu per a tercers.

Instal·lació

services:
  homepage:
    image: ghcr.io/gethomepage/homepage:latest
    container_name: homepage
    ports:
      - "3010:3000"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro
      - homepage_config:/app/config
    restart: unless-stopped

volumes:
  homepage_config:

Configuració YAML

  • settings.yaml: títol, tema, fons, color d'accent.
  • services.yaml: llista de serveis.
  • widgets.yaml: widgets (resources, search, etc.).
  • bookmarks.yaml: dreceres ràpides.
  • docker.yaml: integració Docker.

Services.yaml bàsic

- BernatLab:
    - Portainer:
        href: http://hortosona:9000
        description: Administracio Docker
        icon: portainer
        siteMonitor: http://hortosona:9000
    - Uptime Kuma:
        href: http://hortosona:3001
        description: Monitoratge de serveis
        icon: uptime-kuma
        siteMonitor: http://hortosona:3001
        widget:
            type: uptime-kuma
            url: http://uptime-kuma:3001
            sitesMonitorSlug: bernatlab

Widgets destacats

  • resources: CPU, RAM, disc, temperatura de la RPi.
  • uptime-kuma: estat dels monitors.
  • search: cerca ràpida DuckDuckGo.
  • weather: temps (Open-Meteo, sense API key).
  • docker: llista contenidors amb el seu estat.

Settings.yaml

title: BernatLab
background:
    opacity: 30
    image: https://...
color: slate
theme: dark
favicon: /icons/favicon.ico

Icones personalitzades

Homepage té ~500 icones preconfigurades. Si el servei no n'hi té, munta una icona a /app/config/icons/ (SVG, PNG, ICO).

Hot-reload

Editar YAML = recàrrega automàtica en 5-10 segons. Errors de sintaxi es veuen a docker logs homepage.

🛠️ Exercici pràctic (30-45 min)

Instal·lar Homepage, configurar serveis del BernatLab, deixar un dashboard personalitzat.

Pas 1: Afegeix al compose (5 min)

Edita ~/homelab/docker/docker-compose.yml amb Homepage. Fes docker compose up -d.

Pas 2: Accedeix (5 min)

Obre http://hortosona:3010.

Pas 3: Bind mount (10 min)

Crea ~/homelab/config/homepage/, copia la config del contenidor, munta al host.

Pas 4: Services.yaml (15 min)

Substitueix el fitxer amb BernatLab (Portainer, Uptime, Whoami) + grups externs.

Pas 5: Widgets i settings (5 min)

Configura resources + search, personalitza títol, tema, color.

Pas 6: Comprova i documenta

Comprova al navegador i al mòbil amb Tailscale. Documenta a diari.md.

Validació

  • ☐ Homepage corre a http://hortosona:3010.
  • ☐ Configuració persistent (bind mount).
  • ☐ ≥ 5 serveis al dashboard.
  • ☐ Widget resources funciona.
  • ☐ Widget search funciona.
  • ☐ Títol i tema personalitzats.
  • ☐ Has documentat l'experiència.
