📖 Resum del capítol

La idea clau

SSH (terminal remot) + Tailscale (VPN) = accés segur al BernatLab des de qualsevol lloc. La RPi (hortosona) té IP Tailscale 100.x.y.z.

Conceptes de xarxa

  • IP: identificador del dispositiu (p. ex. 100.x.y.z).
  • Port: número de servei (22=SSH, 80=HTTP, 443=HTTPS, 9000=Portainer, 3001=Uptime Kuma).
  • DNS: tradueix noms a IPs.
  • NAT / port forwarding: el que caldria tocar al router si no tinguéssim Tailscale.

SSH: la porta d'entrada

ssh bernat@hortosona
# o per IP
ssh bernat@100.x.y.z
ssh bernat@192.168.1.50

Primera vegada: confirma la fingerprint del servidor. Després: contrasenya. Sortir: exit o Ctrl+D.

Claus SSH: sense contrasenya (i més segur)

Parell de claus: privada (al portàtil, com una master key) i pública (al servidor, com un pany).

# Generar al portàtil
ssh-keygen -t ed25519 -C "bernat@portatil-2026"

# Copiar la pública a la RPi (Linux/Mac/WSL)
ssh-copy-id bernat@hortosona

# Windows PowerShell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh bernat@hortosona "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

Configuració SSH al portàtil

Edita ~/.ssh/config:

Host hortosona
    HostName 100.x.y.z
    User bernat
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

Host rpi
    HostName hortosona
    User bernat

Ara ssh hortosona o ssh rpi funcionen directament.

Tailscale: la xarxa màgica

VPN basada en WireGuard. Crea una xarxa privada entre dispositius sense tocar el router.

# A la RPi
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
sudo tailscale status
tailscale ip -4

Avantatges: sense port forwarding, xifrat d'extrem a extrem, MagicDNS, gratuït fins a 100 dispositius.

MagicDNS

Gràcies a Tailscale, pots fer ssh bernat@hortosona en lloc d'usar la IP. Tailscale resol el nom a la IP correcta automàticament.

Comandes útils

tailscale ip -4                    # la meva IP Tailscale
tailscale status                   # dispositius de la xarxa
sudo tailscale serve 3000          # compartir servei temporal
ping 8.8.8.8                       # test Internet
curl -I https://google.com         # test HTTPS

🛠️ Exercici pràctic (30-45 min)

Configurar l'accés remot segur a la RPi amb claus SSH i Tailscale. Acabaràs podent entrar amb ssh bernat@hortosona sense contrasenya.

Pas 1: Instal·la Tailscale a la RPi (10 min)

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
sudo tailscale status
tailscale ip -4

Pas 2: Instal·la Tailscale al portàtil

Des de tailscale.com/download. Autentica't amb el MATEIX compte que a la RPi.

Pas 3: Genera una clau SSH al portàtil (10 min)

ssh-keygen -t ed25519 -C "bernat@portatil-2026"

Pas 4: Copia la clau pública a la RPi (10 min)

# Linux/Mac/WSL
ssh-copy-id bernat@hortosona

# Windows PowerShell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh bernat@hortosona "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

Pas 5: Configura ~/.ssh/config (5 min)

Host hortosona
    HostName 100.x.y.z
    User bernat
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

Host rpi
    HostName hortosona
    User bernat

Pas 6: Desactiva autenticació per contrasenya (opcional)

Edita /etc/ssh/sshd_config a la RPi: PasswordAuthentication no i sudo systemctl restart ssh. Compte: fes-ho NOMÉS quan la clau funcioni.

Pas 7: Documenta

Crea book/curs/M1/04-xarxa-ssh-tailscale/configuracio.md amb les IPs, la fingerprint i captures de tailscale status.

Validació

  • ☐ Tailscale instal·lat a RPi i portàtil amb el mateix compte.
  • ☐ tailscale status mostra ambdós dispositius.
  • ☐ Has generat una clau SSH al portàtil.
  • ☐ La clau pública és a ~/.ssh/authorized_keys de la RPi.
  • ☐ ssh bernat@hortosona entra sense contrasenya.
  • ☐ Has configurat ~/.ssh/config al portàtil.
  • ☐ Has documentat la configuració.

  1. SSH = port 22.
  2. Format = usuari@màquina.
