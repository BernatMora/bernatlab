File Browser — navegador de fitxers web

Interfície web per navegar, pujar, baixar, editar i compartir fitxers. Com un "Google Drive" però allotjat a casa. Cap M2-12.

Node-RED — el Lego de l'automatització

Eina de programació visual low-code basada en fluxos. Connectes nodes per crear automatitzacions. Cap M3-19.

MQTT — protocol de missatgeria IoT

Protocol publish/subscribe lleuger. Broker Eclipse Mosquitto. Topic, payload, QoS, retain. Cap M4-25.

InfluxDB — base de dades de sèries temporals

TSDB optimitzada per dades amb marca temporal. Milions de punts/dia, agregacions eficients. Cap M4-26.

Grafana — el rei de les gràfiques

Plataforma de visualització. Dashboards, gràfiques, alertes. Suporta 50+ fonts de dades. Cap M4-27.

PostgreSQL — base de dades relacional

Open-source SQL avançat. Transaccions ACID. Per a Gitea, Nextcloud, Paperless, Bookstack, Authentik. Cap M2-15.

LoRa / LoRaWAN — comunicació de llarg abast

Ràdio de baix consum i llarg abast (1-10 km). 868 MHz a Europa. Gateway + ChirpStack + sensors. Cap M5-31.

🛠️ Exercici pràctic (30-45 min)

Planificar el teu BernatLab personal: quins serveis, amb quin ordre, quins objectius. Més de reflexió que de teclejar ordres.

Pas 1: Inventari actual (10 min)

Crea book/curs/M1/10-full-de-ruta/inventari.md amb hardware, serveis actius, limitacions.

Pas 2: Visió a 6 mesos (15 min)

Crea visio-6-mesos.md amb serveis desitjats, mòdul prioritari, projecte concret, recursos addicionals.

Pas 3: Primer pas concret (10 min)

Defineix el primer pas concret que faràs la setmana vinent. Afegeix-lo a la visió a 6 mesos.

Pas 4: Planifica l'arquitectura (10 min)

Dibuixa l'arquitectura desitjada (ASCII, draw.io, o a mà). Desa a docs/arquitectura-futura.md.

Pas 5: Documenta i commita (5 min)

git add && git commit -m "Documenta inventari i visio..."

Validació

  • ☐ Inventari actual complet.
  • ☐ Visió a 6 mesos redactada.
  • ☐ Primer pas concret definit.
  • ☐ Arquitectura futura dibuixada.
  • ☐ Commit fet al repo.
