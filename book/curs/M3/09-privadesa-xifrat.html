📖 Resum del capítol

La idea clau

Al BernatLab tinc dades que vull mantenir privades i segures: contrasenyes de serveis, claus SSH, fitxers amb dades personals (DNI, adreces, factures), backups al núvol, etc. Si algú té accés físic a la RPi o si el meu núvol es compromet, vull que les dades estiguin xifrades de manera que només jo les pugui llegir.

En aquest capítol veurem dues eines principals per xifrar: GPG (l'estàndard clàssic) i age (una eina moderna molt més simple). També parlarem d'estratègies per protegir les dades.

Què és el xifratge?

Xifrar és transformar dades de manera que només qui té la clau les pugui llegir. Hi ha dos tipus principals:

  • Xifratge simètric: la mateixa clau xifra i desxifra (contrasenya).
  • Xifratge asimètric: dues claus, pública i privada (GPG/SSH).

Al BernatLab faig servir els dos:

  • Simètric (age + passphrase) per xifrar fitxers individuals.
  • Asimètric (claus SSH) per accedir al servidor.

GPG: l'estàndard clàssic

GPG (Gnu Privacy Guard) és la implementació open source del standard OpenPGP. Permet:

  • Xifrar fitxers amb una clau pública.
  • Desxifrar amb la teva clau privada.
  • Firmar documents per garantir que no s'han alterat.
  • Verificar signatures d'altres.

Ús bàsic

# Generar un parell de claus
gpg --full-generate-key

# Llistar les claus
gpg --list-keys

# Xifrar un fitxer
gpg --encrypt --recipient bernat@bernatlab.cat fitxer.txt

# Desxifrar
gpg --decrypt fitxer.txt.gpg > fitxer.txt

# Xifrar nomes amb simetria (contrasenya)
gpg --symmetric fitxer.txt

Quan usar GPG

GPG és la millor opció quan necessites compatibilitat universal, vols firmar correus o documents, o treballes amb correu xifrat. NO és la millor opció quan només vols xifrar un fitxer ràpid (age és més simple).

age: el modern

age (https://age-encryption.org) és una eina de xifratge moderna (2019) que té com a objectiu substituir GPG en casos simples. Característiques:

  • Molt simple: 3 ordres principals.
  • Molt segura: X25519, ChaCha20-Poly1305, HMAC-SHA256.
  • Sense configuració: no cal keyring.
  • Curta: codi petit.
  • Claus curtes: frases humanes o cadenes curtes.

Ús bàsic

# Instal·la age
sudo apt install age

# Genera un parell de claus
age-keygen -o key.txt
# Mostra la clau publica per stdout

# Xifrar amb clau publica
age -r age1ql3z7hjy54pw3hyww5ayyfg7zqgvc7w3j2elw8zmrj2vn5... \
  -o secrets.txt.age secrets.txt

# Desxifrar amb clau privada
age -d -i key.txt -o secrets-restored.txt secrets.txt.age

# Xifrar amb contrasenya (simetric)
age -p -o secrets.txt.age secrets.txt

# Desxifrar
age -d -o secrets-restored.txt secrets.txt.age

Quan usar age

age és la millor opció quan vols xifrar fitxers individuals ràpidament, no necessites firmar res, la simplicitat és important.

Al BernatLab faig servir age per defecte per xifrar fitxers petits (scripts, configuracions amb secrets). Per a fitxers grans o carpetes, faig servir restic (que ja xifra amb AES-256).

Estratègia de privadesa al BernatLab

Algunes regles que segueixo:

  1. Els secrets (.env, claus SSH) mai van al git ni al núvol en clar. Els xifro amb age abans.
  2. Els fitxers personals (factures, DNI escanejat) es desen xifrats amb age.
  3. Els backups al núvol (restic) ja van xifrats per defecte amb AES-256.
  4. Les comunicacions (Tailscale, SSH, HTTPS) ja van xifrades per disseny.
  5. Les contrasenyes es desen a un gestor de contrasenyes (Vaultwarden).

Gestors de contrasenyes

Un gestor de contrasenyes emmagatzema totes les teves contrasenyes xifrades amb una master password. Al BernatLab faig servir:

  • Vaultwarden (Bitwarden auto-allotjat) per a totes les contrasenyes.
  • KeePassXC localment per a notes sensibles.

Mai guardo contrasenyes en fitxers de text plans, ni en un navegador, ni en un paper.

Bones pràctiques

  1. No xifris el que no cal: xifrar té cost.
  2. Guarda les claus en un lloc segur: la clau privada d'edat en un USB xifrat.
  3. Practica la restauració: xifra un fitxer, esborra l'original, restaura'l.
  4. Fes servir eines modernes: age és més segur i més simple que GPG per a casos bàsics.
  5. Automatitza el que puguis.

Connexions amb altres capítols

  • Cap 2 — restic ja xifra els backups amb AES-256.

  • Cap 8 — Syncthing pot sincronitzar carpetes xifrades.

🛠️ Exercici pràctic (30-40 min)

Instal·lar age, generar un parell de claus, xifrar i desxifrar un fitxer, practicar amb GPG simètric, i crear un script per xifrar/desxifrar.

Pas 1: Instal·la age i GPG (5 min)

sudo apt update
sudo apt install -y age gpg

age --version
gpg --version

Pas 2: Genera un parell de claus amb age (5 min)

mkdir -p /home/pi/bernatlab/proves/xifrat
cd /home/pi/bernatlab/proves/xifrat

# Genera les claus
age-keygen -o age-key.txt 2> age-pub.txt

# Mostra la clau publica
cat age-pub.txt

# Mostra la clau privada (NO la comparteixis!)
cat age-key.txt

# Important: dona-li permisos 600
chmod 600 age-key.txt

Pas 3: Xifra i desxifra un fitxer (5 min)

# Crea un fitxer amb dades sensibles
cat > secrets.txt <<EOF
Les meves contrasenyes importants:
- Email: super-secret-pass-2025
- GitHub: github-token-12345
EOF

# Xifra amb clau publica
PUBKEY=$(cat age-pub.txt)
age -r "$PUBKEY" -o secrets.txt.age secrets.txt

# Comprova
ls -la secrets.txt*
file secrets.txt.age
# Hauria de dir "data"

# Esborra l'original
rm secrets.txt
ls secrets.txt
# ls: cannot access... No such file or directory

# Restaura
age -d -i age-key.txt -o secrets-restored.txt secrets.txt.age
cat secrets-restored.txt
# Hauries de veure les contrasenyes originals

Pas 4: Xifratge simètric amb age (5 min)

# Xifra amb contrasenya
age -p -o notes.age notes.txt
# Et demana una contrasenya

# Desxifra
age -d -o notes-restored.txt notes.age
# Et demana la contrasenya

Pas 5: Prova GPG (5 min)

# Xifra simètricament amb GPG
echo "un altre secret" > gpg-test.txt
gpg --symmetric --batch --passphrase "test-2025" -o gpg-test.txt.gpg gpg-test.txt

# Comprova
file gpg-test.txt.gpg

# Desxifra
gpg --batch --passphrase "test-2025" -o gpg-restored.txt gpg-test.txt.gpg
cat gpg-restored.txt

Pas 6: Crea un script de xifrar/desxifrar (5 min)

cat > /home/pi/bernatlab/scripts/xifrar.sh <<'EOF'
#!/bin/bash
# Xifra un fitxer amb age

if [ $# -ne 1 ]; then
  echo "Us: $0 <fitxer>"
  exit 1
fi

FITXER=$1
PUBKEY="posa_aqui_la_teva_clau_publica_age"

if [ ! -f "$FITXER" ]; then
  echo "Error: $FITXER no existeix"
  exit 1
fi

age -r "$PUBKEY" -o "$FITXER.age" "$FITXER"
echo "Xifrat: $FITXER.age"
EOF

chmod +x /home/pi/bernatlab/scripts/xifrar.sh

# Prova'l
/home/pi/bernatlab/scripts/xifrar.sh secrets.txt

Validació

  • ☐ Has instal·lat age i GPG.
  • ☐ Has generat un parell de claus age.
  • ☐ Has xifrat i desxifrat un fitxer amb age (clau pública).
  • ☐ Has xifrat simètricament amb contrasenya.
  • ☐ Has provat GPG simètric.
  • ☐ Has creat un script per xifrar.

Resum ràpid

  1. Simètric = mateixa clau per xifrar i desxifrar.
  2. age vs GPG = simplicitat.
  3. Generar claus age = age-keygen.
  4. Xifrat en repòs = xifrat al disc.
  5. Algorisme age = ChaCha20-Poly1305.
  6. Master password = la clau del gestor.
  7. Clau privada al disc = perill.
  8. SSH = asimètric (clau pública + privada).
