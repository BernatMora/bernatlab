📖 Resum del capítol

La idea clau

Si tens un servei en produccio, necessites backups. Sense backup, qualsevol fallada et pot fer perdre totes les dades. La bona noticia es que Docker facilita els backups perque tot es fitxers.

Regla 3-2-1

  • 3 copies de les dades (l'original + 2 backups)
  • 2 suports diferents (per exemple, SD + disc USB extern, o SD + núvol)
  • 1 fora de la maquina (per exemple, en un núvol o un servidor remot)

Que cal fer backup

Tot el que no es pot tornar a generar:

  1. Volums Docker (les dades: base de dades, fitxers, configuracio).
  2. Configuracio (fitxers docker-compose.yml, .env).
  3. Secrets (contrasenyes, claus - xifrats!).
  4. Imatges personalitzades (si n'has construit alguna).

El que NO cal fer backup: les imatges de Docker Hub (es poden tornar a baixar), el sistema operatiu.

Estratègies de backup

1. Backup de volums

Els volums son carpetes a /var/lib/docker/volumes/. Per fer-ne backup, usem un contenidor temporal:

# Backup d'un volum nomenat
docker run --rm \
  -v dades-meves:/origen:ro \
  -v ~/backups:/desti \
  alpine tar czf /desti/dades-meves-$(date +%F).tar.gz -C /origen .

# Restaurar
docker volume create dades-meves-restaurades
docker run --rm \
  -v dades-meves-restaurades:/desti \
  -v ~/backups:/origen \
  alpine tar xzf /origen/dades-meves-2024-01-15.tar.gz -C /desti

2. Backup de base de dades

# PostgreSQL
docker exec postgres-container pg_dump -U user dbname > backup.sql

# MySQL / MariaDB
docker exec mariadb-container mysqldump -u root -p dbname > backup.sql

# MongoDB
docker exec mongo-container mongodump --archive > backup.archive

3. Backup de fitxers de configuracio

tar czf config-backup.tar.gz /home/pi/bernatlab/

# Important: xifrar si hi ha secrets!
gpg --symmetric --cipher-algo AES256 config-backup.tar.gz

4. Backup incremental

# Primer backup: sencer
rsync -a /home/pi/dades/ /backup/daily.0/

# Segon backup: nomes els canvis
rsync -a --link-dest=/backup/daily.0 /home/pi/dades/ /backup/daily.1/

5. Backup al núvol

# Amb rclone
rclone sync /backup/daily.0 b2:bernatlab-backup/

# Amb restic
restic -r b2:bernatlab-backup:/ backup /home/pi/dades

Automatitzacio amb cron

crontab -e

# Afegir una feina que fa backup cada nit a les 3 AM
0 3 * * * /home/pi/scripts/backup-volums.sh >> /var/log/backup.log 2>&1

Verificar els backups

Un backup que no s'ha verificat no es un backup.

# Verificar que un .tar.gz no esta corrupte
tar tzf backup.tar.gz > /dev/null && echo "OK" || echo "CORRUPT!"

# Restaurar a un directori temporal i comprovar
mkdir /tmp/test-restore
tar xzf backup.tar.gz -C /tmp/test-restore
diff -r /tmp/test-restore /origen/

Xifrat

Si els teus backups contenen dades sensibles, xifra'ls:

# Xifrar amb GPG
gpg --symmetric --cipher-algo AES256 backup.tar.gz

# Desxifrar
gpg -d backup.tar.gz.gpg > backup.tar.gz

🛠️ Exercici pràctic (40-60 min)

Crear una estrategia de backup complerta per a contenidors Docker.

Pas 1: Prepara l'entorn (5 min)

mkdir -p ~/backup-test/scripts
mkdir -p ~/backup-test/backups
cd ~/backup-test

docker run -d --name test-db -e POSTGRES_PASSWORD=test -e POSTGRES_DB=testdb postgres:16-alpine
sleep 5
docker exec test-db pg_isready -U postgres
docker exec test-db psql -U postgres -d testdb -c "CREATE TABLE proves (id SERIAL PRIMARY KEY, nom TEXT);"
docker exec test-db psql -U postgres -d testdb -c "INSERT INTO proves (nom) VALUES ('Bernat'), ('Maria'), ('Joan');"

Pas 2: Crea un volum amb dades (5 min)

docker volume create dades-test
docker run -d --name test-vol -v dades-test:/app/data alpine sh -c "echo 'Foto 1' > /app/data/foto1.txt && echo 'Foto 2' > /app/data/foto2.txt && sleep 3600"
docker exec test-vol ls /app/data

Pas 3: Script de backup basic (10 min)

Crea ~/backup-test/scripts/backup-basic.sh:

#!/bin/bash
set -e
BACKUP_DIR=~/backup-test/backups
DATA=$(date +%F)
mkdir -p ${BACKUP_DIR}

echo "=== Inici del backup ${DATA} ==="

docker run --rm \
  -v dades-test:/origen:ro \
  -v ${BACKUP_DIR}:/desti \
  alpine tar czf /desti/vol-dades-test-${DATA}.tar.gz -C /origen .

docker exec test-db pg_dump -U postgres testdb > ${BACKUP_DIR}/db-testdb-${DATA}.sql

ls -lh ${BACKUP_DIR}
echo "=== Backup finalitzat ==="
chmod +x ~/backup-test/scripts/backup-basic.sh
~/backup-test/scripts/backup-basic.sh

Pas 4: Restaurar el backup (10 min)

docker stop test-vol test-db
docker rm test-vol test-db
docker volume rm dades-test
docker volume prune -f

docker volume create dades-test
LATEST_VOL=$(ls -t ~/backup-test/backups/vol-dades-test-*.tar.gz | head -1)
docker run --rm \
  -v dades-test:/desti \
  -v ~/backup-test/backups:/backup \
  alpine tar xzf /backup/$(basename $LATEST_VOL) -C /desti

docker run --rm -v dades-test:/data alpine ls /data
docker run --rm -v dades-test:/data alpine cat /data/foto1.txt

Pas 5: Script complet amb retencio (15 min)

Crea ~/backup-test/scripts/backup-complet.sh:

#!/bin/bash
set -e
BACKUP_DIR=~/backup-test/backups
RETENTION_DAYS=7
DATA=$(date +%F)
mkdir -p ${BACKUP_DIR}

log() { echo "[$(date '+%F %T')] $@"; }

log "=== Inici del backup ${DATA} ==="

log "Backup del volum..."
docker run --rm \
  -v dades-test:/origen:ro \
  -v ${BACKUP_DIR}:/desti \
  alpine tar czf /desti/vol-dades-test-${DATA}.tar.gz -C /origen .

log "Dump de la base de dades..."
docker exec test-db pg_dump -U postgres testdb > ${BACKUP_DIR}/db-testdb-${DATA}.sql
gzip ${BACKUP_DIR}/db-testdb-${DATA}.sql

log "Verificant backups..."
for fitxer in ${BACKUP_DIR}/vol-dades-test-${DATA}.tar.gz; do
  if tar tzf $fitxer > /dev/null 2>&1; then
    log "OK: $fitxer"
  else
    log "ERROR: $fitxer corrupte!"
    exit 1
  fi
done

log "Esborrant backups antics (>${RETENTION_DAYS} dies)..."
find ${BACKUP_DIR} -type f -mtime +${RETENTION_DAYS} -delete

ls -lh ${BACKUP_DIR}
log "=== Backup finalitzat amb exit ==="
chmod +x ~/backup-test/scripts/backup-complet.sh
~/backup-test/scripts/backup-complet.sh

Pas 6: Automatitzar amb cron (5 min)

crontab -e
# Afegeix:
0 3 * * * /home/pi/backup-test/scripts/backup-complet.sh >> /var/log/backup.log 2>&1

Pas 7: Neteja

docker stop test-db
docker rm test-db
docker volume rm dades-test
docker volume prune -f
crontab -e  # esborra la linia afegida

Validació

  • ☐ Has creat un script que fa backup d'un volum i una base de dades.
  • ☐ Has restaurat amb exit un volum perdut.
  • ☐ Has afegit retencio automatica al script.
  • ☐ Has verificat que els fitxers de backup no son corruptes.
  • ☐ Has configurat cron per executar el backup automaticament.
  • ☐ Has fet una còpia al núvol o has simulat el procés.

Resum ràpid

  1. 3-2-1 = 3 copies, 2 suports, 1 fora.
  2. Volum = contenidor temporal amb tar.
  3. pg_dump = dump SQL de la base de dades.
  4. Xifrat = protegir dades si es perden.
  5. Verificat = provat de restaurar.
  6. Incremental al núvol = restic, borgbackup, rclone.
  7. Automatitzar = cron.
  8. Frequencia minima = 1 cop al dia.
