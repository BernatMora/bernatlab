🧠 Mètode d'aprenentatge

Aquest curs aplica el mètode de repàs espaiat (spaced repetition) — la ciència cognitiva diu que calen entre 3 i 5 repàs per retenir informació nova. Per cada capítol:

  1. Dia 0 — Llegeix el resum (5-10 min) + fes el quiz per terminal (15-20 min) + fes l'exercici pràctic al teu servidor (20-60 min).
  2. Dia 3 — Repassa les preguntes que has fallat.
  3. Dia 15 — Fes 3-5 preguntes aleatòries del capítol.
  4. Dia 45 — Repassa 3-5 preguntes aleatòries més.

El sistema et preguntarà per les coses just quan les estàs a punt d'oblidar. Així fixes el coneixement a la memòria de llarg termini.

🚀 Com fer-lo servir

Pas 1. Clona el BernatLab al teu PC (si no el tens):

git clone https://github.com/BernatMora/bernatlab.git
cd bernatlab

Pas 2. Activa el Python virtual:

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (bash / Git Bash)
source .venv/Scripts/activate

# macOS / Linux
source .venv/bin/activate

Pas 3. Fes el quiz del capítol que vulguis:

# Llistar tots els capítols disponibles
python book/curs/quiz.py --list

# Fer el quiz del M1, capítol 1
python book/curs/quiz.py --m1 1

# Veure estadístiques globals
python book/curs/quiz.py --stats

# Repàs espaçat (5 preguntes aleatòries de les que has fallat)
python book/curs/quiz.py --review
