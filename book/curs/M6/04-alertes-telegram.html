📖 Resum del capítol

La idea clau

Tenir un dashboard bonic no serveix de res si no mires la pantalla. El sistema 24/7 ha de ser PROACTIU: t'ha d'avisar QUAN alguna cosa va malament, no esperar que tu miris. Telegram es perfecte per aixo perque el portem al movil sempre, es gratis, i permet crear bots i grups amb pocs passos.

Per que Telegram i no altres?

  • Sempre el portem al movil: l'alerta arriba a la butxatera.
  • Gratis i sense limits: fins a 30 missatges/segon per bot.
  • API senzilla: pots enviar un missatge amb una sola crida HTTP.
  • Grups: pots tenir un grup "BernatLab Alertes" amb qui vulguis.
  • Markdown i botons: pots enviar missatges rics amb links als dashboards.
  • Sense registre complicat: nomes cal un numero de telefon.

Anatomia d'una alerta

Una alerta te quatre parts:

  1. Condicio: QUAN passa alguna cosa. P.ex. "CPU > 80% durant 5 minuts".
  2. Avaluacio: cada quan es comprova.
  3. Destinacio: ON s'envia. Telegram, email, etc.
  4. Missatge: QUE es diu. Text amb dades de l'incident.

Tambe te cicles de vida: Inactive (tot be), Pending (condicio activa pero no prou temps), Firing (s'envia l'alerta), Resolved (s'ha resolt).

Alertmanager: el carter de Prometheus

Alertmanager es un servei independent que rep les alertes de Prometheus, les agrupa, silencia, i envia al canal que toqui. Es separa de Prometheus perque si Prometheus reinicia, Alertmanager recorda quines alertes estan actives.

  alertmanager:
    image: prom/alertmanager:latest
    container_name: alertmanager
    restart: unless-stopped
    user: "0:0"
    volumes:
      - ./alertmanager/alertmanager.yml:/etc/alertmanager/alertmanager.yml
    command:
      - '--config.file=/etc/alertmanager/alertmanager.yml'
      - '--storage.path=/alertmanager'
    ports:
      - "9093:9093"

Crear el bot de Telegram

  1. Obre Telegram i busca @BotFather.
  2. Envia /newbot.
  3. Dona un nom (per exemple "BernatLab Alerts").
  4. Dona un username unic (acabant en bot).
  5. Rebràs un token. Guarda'l!

Per obtenir el chat_id:

  1. Afegeix el bot a un grup o usa el teu xat privat.
  2. Envia qualsevol missatge al grup.
  3. Visita https://api.telegram.org/bot<TOKEN>/getUpdates.
  4. Busca el chat.id al JSON.

Configuracio d'Alertmanager

global:
  resolve_timeout: 5m

route:
  receiver: 'telegram-bernatlab'
  group_by: ['alertname', 'instance']
  group_wait: 30s
  group_interval: 5m
  repeat_interval: 4h

receivers:
  - name: 'telegram-bernatlab'
    telegram_configs:
      - bot_token: 'EL_TELEGRAM_BOT_TOKEN'
        chat_id: EL_CHAT_ID
        parse_mode: 'Markdown'
        message: |
          🚨 *{{ .GroupLabels.alertname }}*
          {{ .CommonAnnotations.summary }}

inhibit_rules:
  - source_match:
      severity: 'critical'
    target_match:
      severity: 'warning'
    equal: ['alertname', 'instance']

Regles d'alerta a Prometheus

groups:
  - name: bernatlab_sistema
    interval: 30s
    rules:
      - alert: CPUAlta
        expr: 100 - (avg by(instance)(rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 80
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "CPU alta a {{ $labels.instance }}"
          description: "CPU al {{ $value }}% durant 5 minuts"

      - alert: DiscPle
        expr: (node_filesystem_avail_bytes{mountpoint="/"} / node_filesystem_size_bytes{mountpoint="/"}) * 100 < 10
        for: 10m
        labels:
          severity: critical
        annotations:
          summary: "Disc ple a {{ $labels.instance }}"
          description: "Nomes queden {{ $value }}% d'espai"

      - alert: RPiDown
        expr: up{job="node"} == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "RPi no respon"
          description: "Node Exporter no respon desde fa 1 minut"

Bones practiques d'alertes

  • No t'espamegis: 5 alertes MOLT significatives millor que 20 sorolloses.
  • Usa for:: 5-10 min evita falses alarmes per pics puntuals.
  • Descripcions utils: "CPU al 95% a rpi-bernatlab desde les 14:32".
  • Links als dashboards: amb un click veus el context.
  • Inhibit rules: si un node esta caigut, no cal avisar dels seus contenidors.
  • Resolve_timeout: s'envia un "Resolved" quan tot torna a la normalitat.

Alertes per SMS o telefonada

Per a coses CRITIQUES (incendi, intrusio, pujada de temperatura extrema):

  • Twilio: API de telefonada/SMS, amb free tier limitat.
  • Alertmanager + twilio: integracions no oficials.
  • Pushover: app de pagament (5 EUR) amb notificacions critiques amb so fort.

Silenci temporal (silences)

Quan estàs treballant en la RPi i toques coses, no vols rebre alertes constants:

  1. Accedeix a http://IP:9093.
  2. Clica "New Silence".
  3. Tria el match (per exemple, totes les alertes d'una instancia).
  4. Posa durada (per exemple, 1 hora).
  5. Clica "Create".

🛠️ Exercici pràctic (45-60 min)

Crear un bot de Telegram, configurar Alertmanager, i afegir regles d'alerta a Prometheus.

Pas 1: Crea el bot de Telegram (5 min)

Busca @BotFather, envia /newbot, segueix les instruccions i guarda el token.

Pas 2: Obte el chat_id (3 min)

Envia un missatge al bot i visita https://api.telegram.org/bot<TOKEN>/getUpdates. Busca el chat.id.

Pas 3: Instal·la Alertmanager (10 min)

Crea ~/bernatlab/alertmanager/alertmanager.yml amb la configuracio. Afegeix el servei al docker-compose.yml. Puja amb docker compose up -d alertmanager.

Pas 4: Crea regles d'alerta a Prometheus (10 min)

Crea ~/bernatlab/prometheus/rules/bernatlab.yml amb 5 regles: CPU, memoria, disc, temperatura, RPiDown.

Pas 5: Activa les regles i Alertmanager a Prometheus (5 min)

Edita prometheus/prometheus.yml i afegeix rule_files i alerting. Reinicia Prometheus.

Pas 6: Prova que funciona forçant una alerta (15 min)

# En una terminal SSH
yes > /dev/null &
# Espera 6 minuts i hauries de rebre el missatge
killall yes

Comprova a http://IP:9090/alerts i a Telegram.

  • ☐ Has forçat una alerta artificial i has rebut el missatge a Telegram.
