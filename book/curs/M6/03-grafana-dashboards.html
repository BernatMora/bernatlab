📖 Resum del capítol

La idea clau

Prometheus es la base de dades de metricas pero la seva UI es funcional, no maca. Grafana es la capa visual: agafa les dades de Prometheus (o altres fonts) i les presenta en dashboards bonics amb grafs interactius, mapes de calor, gauges i taules. A mes a mes, Grafana tambe pot crear alertes.

Que es Grafana?

Grafana es una eina open source per visualitzar dades de series temporals. Suporta moltes fonts:

  • Prometheus (la que usarem)
  • InfluxDB (cap 6 del M3)
  • MySQL/PostgreSQL (cap 5 del M3)
  • Loki (per logs, ho veurem al cap 5)

El que veus a Grafana es un dashboard compost per panells. Cada panell es un graf, un numero, una taula, o un mapa que consulta dades d'una font.

Instal·lacio a la RPi

  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    restart: unless-stopped
    user: "0:0"
    volumes:
      - ./grafana/data:/var/lib/grafana
      - ./grafana/provisioning:/etc/grafana/provisioning
    environment:
      - GF_SECURITY_ADMIN_USER=admin
      - GF_SECURITY_ADMIN_PASSWORD=canviar_aixo
      - GF_USERS_ALLOW_SIGN_UP=false
    ports:
      - "3000:3000"

Accedeix a http://IP_RPI:3000.

Afegir Prometheus com a font de dades

A la UI de Grafana:

  1. Ves a "Connections" -> "Data sources" -> "Add data source"
  2. Tria "Prometheus"
  3. A "URL" posa http://prometheus:9090 (el nom del servei a docker, no localhost!)
  4. Activa "Default" perque sigui la font per defecte
  5. Guarda i testeja (hauria de dir "Data source is working")

Crear el primer panell

  1. Ves a "Dashboards" -> "New" -> "New dashboard"
  2. Clica "Add visualization"
  3. Escriu una consulta PromQL, per exemple: 100 - (avg by(instance)(rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
  4. Tria el tipus de graf a la dreta
  5. A "Title" posa algo descriptiu
  6. Clica "Apply" i despres "Save dashboard"

Tipus de panell comuns

  • Time series: graf de linies en el temps. Perfecte per CPU, memoria, xarxa.
  • Stat: un numero gran amb color segons el valor.
  • Gauge: velocimetre semicircular.
  • Bar chart: barres per comparacio.
  • Table: taula amb files i columnes.
  • Heatmap: mapa de calor per patrons temporals.

Variables: dashboards parametric

Pas a pas per crear una variable "contenidor":

  1. "Settings" -> "Variables" -> "New variable"
  2. Nom: contenidor
  3. Type: "Query"
  4. Data source: Prometheus
  5. Query: label_values(container_last_seen{name=~".+"}, name)
  6. "Multi-value" i "Include All option" activats
  7. Guarda

Ara pots fer consultes tipus container_memory_usage_bytes{name="$contenidor"}.

Provisioning: configuracio com a codi

# grafana/provisioning/datasources/prometheus.yml
apiVersion: 1
datasources:
  - name: Prometheus
    type: prometheus
    access: proxy
    url: http://prometheus:9090
    isDefault: true
    editable: true
# grafana/provisioning/dashboards/bernatlab.yml
apiVersion: 1
providers:
  - name: 'BernatLab'
    orgId: 1
    folder: 'BernatLab'
    type: file
    disableDeletion: false
    updateIntervalSeconds: 30
    options:
      path: /var/lib/grafana/dashboards

Dashboards essencials del BernatLab

  1. Vista general del sistema: CPU, memoria, disc, xarxa, temperatura, uptime.
  2. Contenidors Docker: llista amb estat, CPU per contenidor, memoria.
  3. Serveis aplicacio: Home Assistant, InfluxDB, Grafana.
  4. Xarxa: latencia al router, DNS resolution time.

Compartir dashboards

IDs utils de grafana.com:

  • 1860: Node Exporter Full (complet del sistema).
  • 893: Docker Container (basat en cAdvisor).
  • 13639: Blackbox Exporter (probes HTTP/TCP).

Alertes basiques a Grafana

Encara que Alertmanager es l'eina "pura" d'alertes de Prometheus, Grafana tambe pot crear alertes directament editant un panell, pestanya "Alert". Es mes facil pero menys flexible.

Limitacions a la RPi

  • No abusis dels dashboards: cada panell es una consulta a Prometheus.
  • Desactiva les auto-refresh molt seguides: 30s en lloc de 10s.
  • Limita el periode: no posis "Last 30 days" si no cal.
  • Rendering: compte amb multiples usuaris obrint Grafana al movil.

Connexions amb altres capitols

  • M6 Cap 2 - Prometheus, la font de dades principal.
  • M6 Cap 4 - Alertes: Grafana pot crear-les o pots usar Alertmanager.
  • M3 Cap 6 - InfluxDB tambe es pot visualitzar amb Grafana.
  • M3 Cap 10 - Visualitzacio de dades amb altres eines.

🛠️ Exercici pràctic (45-60 min)

Instal·lar Grafana, connectar-lo a Prometheus, i crear el teu primer dashboard amb panells basics del sistema.

Pas 1: Afegeix Grafana al docker-compose (10 min)

Edita el teu docker-compose.yml i afegeix el servei grafana. Despres:

cd ~/bernatlab
mkdir -p grafana/data grafana/provisioning/datasources grafana/provisioning/dashboards
docker compose up -d grafana

Accedeix a http://IP_RPI:3000.

Pas 2: Connecta Prometheus a Grafana (5 min)

"Connections" -> "Data sources" -> "Add data source" -> "Prometheus" -> URL http://prometheus:9090.

Pas 3: Crea el teu primer panell (15 min)

Consulta CPU: 100 - (avg by(instance)(rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

Type: Time series, Unit: Percent (0-100).

Pas 4: Afegeix 4 panells mes (15 min)

Memoria (Gauge), Disc lliure (Stat), Temperatura (Stat), Contenidors (Table). Veure exercici.md per les consultes exactes.

Pas 5: Importa un dashboard de la comunitat (10 min)

"Dashboards" -> "New" -> "Import" -> ID 1860. Explora'l i esborra el que no necessitis.

Pas 6: Configura el provisioning (5 min)

Crea els fitxers grafana/provisioning/datasources/prometheus.yml i grafana/provisioning/dashboards/bernatlab.yml. Despres docker compose restart grafana.

Validació

  • ☐ Grafana esta corrent i accessible al port 3000.
  • ☐ Has connectat Prometheus com a data source.
  • ☐ Tens un dashboard "BernatLab Sistema" amb almenys 5 panells.
  • ☐ Has importat el dashboard 1860 (Node Exporter Full).
  • ☐ Has creat els fitxers de provisioning.
  • ☐ Has canviat la contrasenya d'admin per defecte.
