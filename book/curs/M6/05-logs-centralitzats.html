📖 Resum del capítol

La idea clau

Els logs son el "diari de bord" del sistema. Tot el que passa, queda escrit. Pero si tens 5 contenidors, mes el sistema operatiu, mes journald, mes sshd... acabes amb logs dispersos per 10 fitxers i contenidors diferents. Els logs centralitzats els uneixen tots en un sol lloc on els pots buscar, filtrar i visualitzar.

Que es un log?

Un log es una linia de text amb un instant de temps i un missatge. Exemples:

2026-05-12T14:32:11 rpi kernel: [12345.678] usb 1-1: new high-speed USB device
2026-05-12T14:32:15 homeassistant ERROR: Connection refused to influxdb
2026-05-12T14:32:18 grafana INFO: dashboard loaded by user admin

Cada linia te un timestamp, una font, un nivell (INFO, WARNING, ERROR) i un missatge.

On son els logs a una RPi amb Docker?

  1. journald: el sistema systemd guarda els logs del sistema aqui.
  2. Fitxers de log tradicionals: /var/log/syslog, /var/log/auth.log.
  3. Logs de Docker: cada contenidor te el seu log accessible amb docker logs.
docker logs homeassistant --tail 100
docker logs -f grafana
journalctl -u docker --since "1 hour ago"
journalctl -f

Per que centralitzar?

  • Un sol lloc on buscar.
  • Filtratge potent: per data, servei, nivell, text.
  • Correlacio: veure que precedeix un error.
  • Retencio configurable: 7 dies, 30, 1 any.
  • Alertes sobre logs: avisar si surt l'error XYZ mes de 10 cops per hora.

Opcions de stack de logs

Tres opcions principals, de menys a mes complexe:

  • journald + logrotate: nomes terminal, la mes simple.
  • Grafana Loki + Promtail: la que recomanem. Lleuger, integra amb Grafana.
  • ELK Stack: Elasticsearch + Logstash + Kibana. Massa pesat per RPi.

Instal·lacio de Grafana Loki

  loki:
    image: grafana/loki:latest
    container_name: loki
    restart: unless-stopped
    user: "0:0"
    volumes:
      - ./loki/data:/loki
      - ./loki/loki-config.yml:/etc/loki/local-config.yaml
    command: -config.file=/etc/loki/local-config.yaml
    ports:
      - "3100:3100"

  promtail:
    image: grafana/promtail:latest
    container_name: promtail
    restart: unless-stopped
    user: "0:0"
    volumes:
      - ./promtail/promtail-config.yml:/etc/promtail/config.yml
      - /var/log:/var/log:ro
      - /var/lib/docker/containers:/var/lib/docker/containers:ro
      - /run/docker.sock:/run/docker.sock:ro
    command: -config.file=/etc/promtail/config.yml

Configuracio de Loki

auth_enabled: false

server:
  http_listen_port: 3100

common:
  instance_addr: 127.0.0.1
  path_prefix: /loki
  storage:
    filesystem:
      chunks_directory: /loki/chunks
      rules_directory: /loki/rules
  replication_factor: 1
  ring:
    kvstore:
      store: inmemory

schema_config:
  configs:
    - from: 2024-01-01
      store: tsdb
      object_store: filesystem
      schema: v13
      index:
        prefix: index_
        period: 24h

limits_config:
  retention_period: 30d
  ingestion_rate_mb: 10
  ingestion_burst_size_mb: 20

Configuracio de Promtail

server:
  http_listen_port: 9080

positions:
  filename: /tmp/positions.yaml

clients:
  - url: http://loki:3100/loki/api/v1/push

scrape_configs:
  - job_name: docker
    docker_sd_configs:
      - host: unix:///var/run/docker.sock
        refresh_interval: 5s
    relabel_configs:
      - source_labels: ['__meta_docker_container_name']
        target_label: 'container'
        regex: '/(.*)'
  - job_name: journal
    journal:
      max_age: 12h
      labels:
        job: systemd
    relabel_configs:
      - source_labels: ['__journal__systemd_unit']
        target_label: 'unit'
  - job_name: syslog
    static_configs:
      - targets: [localhost]
        labels:
          job: syslog
          __path__: /var/log/*.log

Visualitzar a Grafana

"Connections" -> "Data sources" -> "Add data source" -> "Loki", URL http://loki:3100.

Consultes LogQL utils:

# Tots els errors de Home Assistant les ultimes 24h
{container="homeassistant"} |= "error" | json | line_format "{{.message}}"

# Logs de grafana amb nivell ERROR
{container="grafana"} |= "ERROR"

# Logs de sshd (intents fallits d'autenticacio)
{unit="sshd.service"} |= "Failed password"

Rotacio de logs a la RPi

# /etc/logrotate.d/bernatlab
/var/log/bernatlab-health.log {
    daily
    rotate 7
    compress
    missingok
    notifempty
    create 0640 root root
}

journald: configuracio de retencio

[Journal]
SystemMaxUse=200M
SystemKeepFree=1G
SystemMaxFileSize=20M
MaxRetentionSec=2week
sudo systemctl restart systemd-journald

Comandes utils

# Cerca logs per paraula clau
journalctl -u docker | grep -i error

# Logs del ultim reboot
journalctl -b -1

# Coneix el tamany del journal
journalctl --disk-usage

# Forçar neteja del journal
sudo journalctl --vacuum-size=100M
sudo journalctl --vacuum-time=7d

Bones practiques

  • No posis informacio sensible als logs: claus API, contrasenyes, tokens.
  • Usa nivells: DEBUG, INFO, WARNING, ERROR.
  • Estructura els missatges: usa JSON quan puguis.
  • No t'obsessions amb tots els logs: comença amb els 2-3 serveis mes importants.

🛠️ Exercici pràctic (45-60 min)

Instal·lar Loki i Promtail, connectar-los a Grafana, i aprendre a buscar en els logs.

Pas 1: Prepara l'estructura de carpetes (5 min)

cd ~/bernatlab
mkdir -p loki/data
mkdir -p promtail

Pas 2: Crea la configuracio de Loki (5 min)

Edita loki/loki-config.yml amb la configuracio. Veure resum.md per el contingut complet.

Pas 3: Crea la configuracio de Promtail (5 min)

Edita promtail/promtail-config.yml amb la configuracio.

Pas 4: Afegeix Loki i Promtail al docker-compose (10 min)

Edita docker-compose.yml, afegeix els dos serveis i puja'ls amb docker compose up -d loki promtail.

Pas 5: Connecta Loki a Grafana (5 min)

"Connections" -> "Data sources" -> "Add data source" -> "Loki", URL http://loki:3100.

Pas 6: Fes les primeres consultes LogQL (15 min)

A Grafana Explore -> Loki, prova: {container="homeassistant"}, {container="homeassistant"} |= "error", {unit="sshd.service"} |= "Failed".

Pas 7: Limita la mida del journald (5 min)

sudo nano /etc/systemd/journald.conf
# Afegeix:
# [Journal]
# SystemMaxUse=200M
sudo systemctl restart systemd-journald
journalctl --disk-usage

Pas 8: Configura logrotate (5 min)

Crea /etc/logrotate.d/bernatlab amb la configuracio del resum.

Validació

  • ☐ Loki i Promtail corren com a contenidors.
  • ☐ Has afegit Loki com a data source a Grafana.
  • ☐ Pots veure logs dels teus contenidors a Grafana Explore.
  • ☐ Has fet almenys 5 consultes LogQL amb resultats.
  • ☐ Has limitat la mida del journald a 200 MB.
  • ☐ Has creat la configuracio de logrotate pel teu log.

Resum ràpid

  1. Log = linia amb timestamp + missatge.
  2. Servei = journald (systemd-journald).
  3. Docker = docker logs.
  4. Equivalent Prometheus = Loki.
  5. Agent = Promtail.
  6. Llenguatge = LogQL.
  7. Conté text = |=.
  8. Rotacio = logrotate.
