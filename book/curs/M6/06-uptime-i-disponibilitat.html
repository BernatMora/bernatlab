📖 Resum del capítol

La idea clau

Podem tenir tota la monitoritzacio interna que volguem (Prometheus, Grafana, Loki), pero si la RPi queda penjada o el router es reinicia, els nostres monitors tampoc funcionen. Cal un monitor extern que vigili els nostres serveis des de FORA, independent de la nostra infraestructura. Es com tenir un segon ull que mira des de fora.

Que es un SLA?

SLA = Service Level Agreement. Es un compromis sobre la disponibilitat:

  • 99% ("two nines"): 3.65 dies d'inactivitat per any.
  • 99.9% ("three nines"): 8.76 hores d'inactivitat per any.
  • 99.99% ("four nines"): 52.6 minuts d'inactivitat per any.
  • 99.999% ("five nines"): 5.26 minuts d'inactivitat per any.

Que es el temps d'uptime?

Uptime es el percentatge de temps que un servei ha estat disponible:

uptime = (temps_total - temps_caigut) / temps_total * 100

Exemple: 5 minuts caigut cada dia = 35 min/setmana = 99.65% uptime.

Per que cal un monitor EXTERN

Si nomes monitors des de dins, tens dos problemes:

  1. El monitor cau amb el sistema: si la RPi es penja, el monitor tambe.
  2. No detecta fallades de xarxa: si el router es reinicia, la RPi esta be pero no es accessible.

Uptime Kuma: el monitor del BernatLab

Uptime Kuma es una eina open source auto-allotjada. Es l'alternativa a Pingdom, UptimeRobot, etc. pero GRATIS i a casa teva.

Avantatges: gratis, privat, sense limits, multiples tipus de probes, UI bonica, alertes integrades. Desavantatges: si es a la mateixa RPi, cau amb el sistema.

Instal·lacio d'Uptime Kuma

  uptime-kuma:
    image: louislam/uptime-kuma:latest
    container_name: uptime-kuma
    restart: unless-stopped
    volumes:
      - ./uptime-kuma/data:/app/data
    ports:
      - "3001:3001"

Accedeix a http://IP_RPI:3001.

Configurar els monitors basics

  1. "Add New Monitor"
  2. Tipus: HTTP(s)
  3. URL: http://192.168.1.50:8123
  4. Heartbeat interval: 60 segons
  5. Retries: 3
  6. Save

Repeteix per a: Grafana, Prometheus, Home Assistant, Loki, Router (Ping), DNS, Internet.

Status page publica

Uptime Kuma pot generar una status page publica amb l'estat de tots els teus serveis.

A "Status Page" -> "New Status Page":

  1. Nom: "BernatLab"
  2. Slug: bernatlab
  3. Titol: "Serveis del BernatLab"
  4. Descripcio: "Estat dels serveis de la Raspberry Pi de casa"
  5. Tema: clar o fosc
  6. Afegeix els monitors
  7. Guarda

URL: http://IP_RPI:3001/status/bernatlab

Alertes integrades

Uptime Kuma te integracio amb Telegram:

  1. "Settings" -> "Notifications"
  2. "Setup Notification" -> "Telegram"
  3. Bot Token i Chat ID del cap 4
  4. "Test" per verificar
  5. "Save"

Alternativa: serveis cloud

Si vols un monitor REALMENT extern:

  • UptimeRobot (free: 50 monitors, 5 min).
  • Cronitor (free limitat).
  • Healthchecks.io (free: 20 monitors, per cron jobs).
  • Hetrixtools (free: 15 monitors).

Probes importants

  • HTTP amb keyword: comprova que la pagina conté un text esperat.
  • HTTP amb JSON i jq: valida resposta JSON.
  • TCP: comprova que un port esta obert.
  • DNS: comprova que un domini resol correctament.
  • Push: tu envies un senyal periodicament (ideal per backups).

Mesurar el teu uptime real

Uptime Kuma calcula l'uptime per monitor: Last 24 hours, 7 days, 30 days, 365 days. Es MOLT valuos per veure tendencies.

🛠️ Exercici pràctic (30-45 min)

Instal·lar Uptime Kuma, configurar monitors, crear una status page i configurar alertes a Telegram.

Pas 1: Afegeix Uptime Kuma al docker-compose (5 min)

cd ~/bernatlab
mkdir -p uptime-kuma/data

Edita docker-compose.yml, afegeix el servei uptime-kuma, i puja amb docker compose up -d uptime-kuma.

Pas 2: Configura el compte admin (3 min)

Accedeix a http://IP_RPI:3001 i crea l'usuari admin amb una bona contrasenya.

Pas 3: Crea els monitors basics (15 min)

Per cada un: Router (Ping), DNS Google, Internet, Grafana, Prometheus, Home Assistant, SSH (TCP). Substitueix 192.168.1.50 per la IP de la teva RPi.

Pas 4: Configura alerta a Telegram (5 min)

"Settings" -> "Notifications" -> "Setup Notification" -> "Telegram" amb el token i chat ID del cap 4. Fes un test.

Pas 5: Crea una status page publica (10 min)

"Status Page" -> "New Status Page" amb nom "BernatLab" i slug "bernatlab". Afegeix els 7 monitors.

Pas 6: Configura un monitor "push" per backups (5 min)

"Add New Monitor" tipus "Push", heartbeat 86400. Despres integra'l al teu script de backups amb curl.

Validació

  • ☐ Uptime Kuma esta corrent al port 3001.
  • ☐ Has creat almenys 5 monitors basics.
  • ☐ Has configurat l'alerta de Telegram i has rebut un missatge de test.
  • ☐ Has creat una status page publica.
  • ☐ Has configurat un monitor push per backups.
