📖 Resum del capítol

La idea clau

MQTT es un protocol de missatgeria del 1999 dissenyat per connectar sensors via satel·lit. Es basa en un patro pub/sub amb un broker central. Mosquitto es la implementacio de referencia, lleugera i apta per a RPi.

El model publish/subscribe

 Publisher A  ---\
                    \
 Publisher B  ------>[ Broker MQTT ] ---> Subscriber X
                    /
 Publisher C  ---/

Anatomia d'un missatge MQTT

  • Topic: cadena jerarquica amb /.
  • Payload: bytes (text JSON o binari).
  • QoS: 0, 1 o 2.
  • Retain: guarda l'ultim missatge per a nous subscribers.

Exemple:

mosquitto_pub -h localhost -p 1883 -u hort-osona -P secretpass \
   -t "hort-osona/miflora/1B32" \
   -m '{"device":"miflora-1B32","soil_moisture":42}' -q 1 -r

Wildcards

  • + = un sol nivell. hort-osona/miflora/+.
  • # = multiples nivells. hort-osona/#.

QoS: 3 nivells

  • QoS 0: at most once. Telemetria no critica.
  • QoS 1: at least once. Sensors normals.
  • QoS 2: exactly once. Comandes critiques (electrovalvula).

Last Will and Testament (LWT)

Missatge que el broker envia automaticament si el client cau abruptament. Serveix per saber si un gateway ha mort.

client.will_set(
   "hort-osona/status/gateway/rpi1",
   '{"status":"offline"}',
   qos=1, retain=True
)

Retain

El broker guarda l'ultim missatge amb retain i l'entrega als nous subscribers. Perfecte per a dashboards reactius.

Persistencia i clean_session

Amb persistence true i clean_session=False, el broker retè missatges per a subscribers offline (fins a max_queued_messages).

Seguretat

  • Autenticacio: usuari/password amb password_file.
  • TLS: port 8883 amb certificats. Obligatori si el broker es accessible des d'internet.

Comandes utils

# Publicar
mosquitto_pub -h localhost -p 1883 -u u -P p -t "test/topic" -m "hola" -q 1 -r

# Subscriure a tot
mosquitto_sub -h localhost -p 1883 -u u -P p -t "#" -v

# Subscriure nomes a un patro
mosquitto_sub -h localhost -t "hort-osona/miflora/+" -v

# Subscriure a un unic missatge i sortir
mosquitto_sub -h localhost -t "test/+" -C 1

🛠️ Exercici pràctic (30-45 min)

Muntar Mosquitto amb Docker, crear usuaris, practicar pub/sub, i fer una aplicacio Python amb QoS 1 i LWT.

Pas 1: Inicia Mosquitto amb Docker (5 min)

mkdir -p ~/hort-osona/mosquitto/{config,data,log}
docker run --rm -it eclipse-mosquitto:2 \
   sh -c "mosquitto_passwd -c -b /tmp/passwd hort-osona secretpass && \
          mosquitto_passwd -b /tmp/passwd gateway gwpassword && \
          cat /tmp/passwd" > config/passwd
docker run -d --name hort-mosquitto -p 1883:1883 \
   -v $PWD/mosquitto/config:/mosquitto/config \
   -v $PWD/mosquitto/data:/mosquitto/data eclipse-mosquitto:2

Pas 2: Primer test amb mosquitto_pub/sub (5 min)

mosquitto_sub -h localhost -p 1883 -u hort-osona -P secretpass -t "hort-osona/#" -v
# En una altra terminal:
mosquitto_pub -h localhost -p 1883 -u hort-osona -P secretpass \
   -t "hort-osona/test/salutacio" -m "Hola!"

Pas 3: Practica wildcards (5 min)

Subscriu amb hort-osona/miflora/+ i publica a hort-osona/miflora/1B32, hort-osona/bme/hivernacle, hort-osona/miflora/1B32/extra. Comprova que nomes reps el primer.

Pas 4: Practica retain (5 min)

mosquitto_pub -h localhost -p 1883 -u hort-osona -P secretpass \
   -t "hort-osona/status/hort" -m "OK" -r
mosquitto_sub -h localhost -p 1883 -u hort-osona -P secretpass \
   -t "hort-osona/status/hort" -C 1 -v
# Reps "OK" immediatament

Pas 5: Aplica Python amb QoS 1 i LWT (15 min)

Script Python que publica heartbeat cada 5s amb QoS 1 i retain. Configura LWT per si el client cau. Subscriu a hort-osona/cmd/# per rebre comandes.

Pas 6: Mesurar rendiment (5 min)

Usa mqttbench per generar 1000 missatges a 10 msg/s i mira si la RPi aguanta el ritme.

Validació

  • ☐ Has aixecat Mosquitto amb 2 usuaris.
  • ☐ Has publicat i subscrit amb mosquitto_pub/sub.
  • ☐ Has provat + i #.
  • ☐ Has vist un missatge retain al subscriure't despres.
  • ☐ Has executat el client Python amb QoS 1, LWT i retain.
  • ☐ Has vist el LWT automatic al matar el proces.
