📖 Resum del capítol

La idea clau

LoRa (Long Range) es un modulacio de radio dissenyada per enviar pocs bytes a molta distancia consumint molt poca energia. Un sensor LoRa amb pila pot durar 5 anys enviant dades cada 15 min a 5 km de distancia. A l'Hort Osona l'usem per cobrir els sectors mes allunyats on el BLE no arriba.

Que es LoRa i que no es

LoRa es unicament la capa fisica. Per sobre hi ha:

  • LoRaWAN: protocol de xarxa amb gateways, servidors, AppKeys.
  • LoRa P2P: nomes LoRa, sense xarxa. Dos dispositius parlen directament.

A l'Hort Osona fem LoRa P2P perque nomes tenim 4-5 sensors.

Especificacions del SX1262 868 MHz

  • Frequencia: 868 MHz (Europa). EUA usa 915 MHz.
  • Modulacio: LoRa (CSS - Chirp Spread Spectrum).
  • Potencia TX: fins +22 dBm; limit legal UE +14 dBm.
  • Sensibilitat RX: fins -148 dBm.
  • Consum TX: ~100 mA a +14 dBm. Consum RX: ~5 mA. Repos: <1 µA.
  • Bitrate: 0.3 a 50 kbps segons SF.

Spreading Factor: la clau de l'abast

El SF controla el trade-off entre abast i velocitat:

SFBitrateTemps a 10 bytesAbast relatiu
SF75.5 kbps50 ms1x
SF91.8 kbps200 ms1.7x
SF120.25 kbps1600 ms3.5x

A l'Hort Osona usem SF9 amb BW 125 kHz, CR 4/5 i sync word 0x12.

Hardware: el modul i l'antena

Opcions populars: Waveshare SX1262 (12€), Lilygo LoRa32 (25€, ESP32+SX1262+OLED), RAK3172 (10€). L'antena SMA 868 MHz de 1/4 d'ona (~8.6 cm) es critica.

Exemple de node amb ESP32

#include 
SX1262 radio = new Module(5, 14, 33, 26);
void setup() {
  radio.begin(868.0, 125.0, 9, 5, 0x12, 14);
}
void loop() {
  radio.transmit("T=21.3 H=58.0");
  delay(900000);  // 15 min
}

Avantatges i limitacions

Pros: cobertura km, autonomia 2-5 anys, robust, sense infraestructura, legal ISM, barat (10€ node).

Contres: duty cycle 1%, banda estreta (pocs kbps), sensible a interferencies, SF/BW han de coincidir als dos extrems, no es IP, P2P no te ACK garantit.

🛠️ Exercici pràctic (40-60 min)

Muntar un node LoRa amb ESP32+SX1262, enviar una lectura de temperatura cada minut, i rebre-la a la RPi gateway.

Pas 1: Connecta el SX1262 a l'ESP32 (10 min)

Cablejat SPI: CS=5, RST=14, DIO1=33, BUSY=26, SCK=18, MISO=19, MOSI=23. Connecta l'antena SMA 868 MHz abans d'encendre.

Pas 2: Configura el PlatformIO (10 min)

mkdir -p ~/proves-lora/node1
cd ~/proves-lora/node1
pio init --board esp32dev

Edita platformio.ini afegint jgromes/RadioLib@^6.0.0 i adafruit/Adafruit BME280 Library.

Pas 3: Escriu el codi del node (15 min)

#include 
SX1262 radio = new Module(5, 14, 33, 26);
Adafruit_BME280 bme;
uint16_t seq = 0;

void setup() {
  radio.begin(868.0, 125.0, 9, 5, 0x12, 14);
}

void loop() {
  char p[64];
  snprintf(p, 64, "{\"dev\":\"node1\",\"seq\":%u,\"t\":%.1f}",
           seq++, bme.readTemperature());
  radio.transmit(p);
  delay(60000);
}
pio run -t upload && pio device monitor

Pas 4: Munta el receptor a la RPi (15 min)

Connecta un altre SX1262 als pins SPI de la RPi. Activa SPI amb raspi-config. Crea gateway_lora.py amb pySX126x i paho-mqtt.

Pas 5: Prova el sistema (5 min)

sudo python3 gateway_lora.py
mosquitto_sub -h localhost -t "hort-osona/lora/#" -v

Pas 6: Mesura l'abast (10 min)

Canvia el delay a 5 segons, surt al carrer amb l'ESP32 i un powerbank, i mira a quants metres es perd la senyal.

Validació

  • ☐ Has connectat el SX1262 a l'ESP32 i a la RPi amb l'antena.
  • ☐ El node envia un JSON cada minut.
  • ☐ La RPi rep el missatge i el publica a MQTT.
  • ☐ Veus el payload amb mosquitto_sub.
  • ☐ Has fet una prova d'abast reial.
