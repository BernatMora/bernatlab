📖 Resum del capítol

La idea clau

InfluxDB es la base de dades de series temporals (TSDB) que l'Hort Osona fa servir per guardar totes les lectures de sensors. Es com una base de dades SQL pero optimitzada per a milions de punts amb timestamp i consultes sobre intervals de temps.

Que es una TSDB

Una TSDB te un model de dades especialitzat:

  • Measurement: el "tipus" de dada.
  • Tags: indexats, per agrupar (device, sector).
  • Fields: els valors numerics.
  • Time: timestamp nanosecond-precision.

Per que InfluxDB i no PostgreSQL

AspectePostgreSQLInfluxDB
TipusRelacionalTime series
Consultes "ultims 7 dies"LentRapidisim
CompressioBaixa~10x

InfluxDB 1.x vs 2.x vs 3.x

  • 1.x: classic, InfluxQL, estable.
  • 2.x: UI web, tasks, checks, dashboards basics. La mes utilitzada.
  • 3.0 (IOx): Rust, columnar, SQL natiu. Nou.

A l'Hort Osona usem 2.7.

Arquitectura d'InfluxDB 2.x

  • Organization (Org): contenidor aillat, e.g. bernatlab.
  • Bucket: contenidor de dades amb retencio. E.g. hort-osona raw 30d + hort-osona-downsampled 1h 365d.
  • Task: proces automatic (downsample, neteja).
  • Check + Notification: alerta quan una query passa un llindar.

El llenguatge Flux

from(bucket: "hort-osona")
  |> range(start: -24h)
  |> filter(fn: (r) => r._measurement == "miflora")
  |> filter(fn: (r) => r._field == "soil_moisture")
  |> aggregateWindow(every: 1h, fn: mean, createEmpty: false)
  |> yield(name: "mitjana")

Escriure dades amb Python

from influxdb_client import InfluxDBClient, Point, WriteOptions
client = InfluxDBClient(url="http://localhost:8086", token="...", org="bernatlab")
write_api = client.write_api(write_options=WriteOptions(batch_size=500))
point = Point("miflora").tag("device", "miflora-1B32") \
    .field("soil_moisture", 42.0) \
    .field("soil_temp_c", 18.5).time(datetime.now(timezone.utc))
write_api.write(bucket="hort-osona", org="bernatlab", record=point)

Consultar dades amb Python

query_api = client.query_api()
result = query_api.query('from(bucket: "hort-osona") |> range(start: -1h) |> filter(fn: (r) => r._measurement == "miflora")')
for table in result:
    for record in table.records:
        print(f"{record.get_time()} {record.get_field()}={record.get_value()}")

Retention i downsampling

Raw 30 dies + downsample 1h 365 dies + downsample 1d 5 anys. Les tasks agreguen automaticament:

option task = {name: "downsample_1h", every: 1h}
from(bucket: "hort-osona")
  |> range(start: -1h, stop: now())
  |> aggregateWindow(every: 1h, fn: mean, createEmpty: false)
  |> to(bucket: "hort-osona-downsampled", org: "bernatlab")

Alertes

Check = consulta que s'avalua periodicament. Notification Rule = accio quan passa (email, webhook, Telegram). A l'Hort Osona tenim una alerta de gelada a bme/temp_c < 2.0 que envia a ntfy.sh.

Line Protocol

curl -XPOST "http://localhost:8086/api/v2/write?org=bernatlab&bucket=hort-osona" \
   -H "Authorization: Token adminsecret" \
   --data 'miflora,device=miflora-1B32 soil_moisture=42,soil_temp_c=18.5 1712926800000000000'

Backups

docker exec hort-influxdb influx backup /tmp/backup
docker cp hort-influxdb:/tmp/backup ./influxdb-backup-$(date +%Y%m%d)

🛠️ Exercici pràctic (40-60 min)

Instal·lar InfluxDB 2.7 amb Docker, crear buckets, escriure dades amb Python, fer consultes amb Flux, i muntar una task de downsampling.

Pas 1: Inicia InfluxDB amb Docker (5 min)

docker run -d --name hort-influxdb -p 8086:8086 \
   -v influxdb-data:/var/lib/influxdb2 \
   -e DOCKER_INFLUXDB_INIT_MODE=setup \
   -e DOCKER_INFLUXDB_INIT_USERNAME=admin \
   -e DOCKER_INFLUXDB_INIT_PASSWORD=adminsecret \
   -e DOCKER_INFLUXDB_INIT_ORG=bernatlab \
   -e DOCKER_INFLUXDB_INIT_BUCKET=hort-osona \
   -e DOCKER_INFLUXDB_INIT_RETENTION=30d \
   influxdb:2.7

Accedeix a http://<ip-rpi>:8086 amb admin/adminsecret. Crea hort-osona-downsampled amb retencio 365d.

Pas 2: Instal·la dependencies Python (5 min)

mkdir -p ~/hort-osona/scripts && cd ~/hort-osona/scripts
python3 -m venv .venv && source .venv/bin/activate
pip install influxdb-client pyyaml python-dotenv

Pas 3: Escriu dades d'exemple (10 min)

Script seed_data.py que genera 1000 punts fake dels ultims 7 dies amb 3 sensors. Comprova a la UI que apareixen.

Pas 4: Consulta amb Python (10 min)

Script query_data.py amb consulta Flux: mitjana horaria de soil_moisture per device, i comptatge de lectures per device.

Pas 5: Crea una task de downsampling (15 min)

A la UI, Tasks -> Create Task. Flux que cada hora agrega raw a 1h al bucket hort-osona-downsampled. Comprova amb influx query.

Pas 6: Crea una alerta de gelada (10 min)

Check amb query: mean(bme/temp_c, -10m) < 2.0. Notification Rule a ntfy.sh. Prova enviant una temperatura baixa amb curl.

  8. Line protocol = format text per escriure punts.
