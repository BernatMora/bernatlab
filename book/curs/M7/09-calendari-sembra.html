📖 Resum del capítol

La idea clau

Tenir sensors que mesuren tot es inutil si no se sap quan sembrar, quan trasplantar i quan collir. El calendari de sembra es la capa d'intel·ligencia que connecta les dades ambientals amb les necessitats de cada cultiu. Es tradueix els grafiques en accions i permet planificar tota la temporada: tomàquets al febrer bajo cobertor, enciams cada 15 dies per collir tota l'estiu, alls al novembre.

Per que cal un calendari de sembra

Si nomes mires els sensors, saps que avui el soll esta a 14°C. Pero no saps si toca sembrar pastanagues o si ja es massa tard per plantar carbasso. El calendari de sembra respon a la pregunta "que faig ara?" en funcio de l'epoca de l'any, la varietat, el clima local, la darrera gelada, la primera gelada, i la rotacio de cultius.

A l'Hort Osona tenim sectors organitzats per families botaniques. El calendari ens diu quan tocar cada sector.

Conceptes basics d'horticultura

  • Sembra directa: la llavor va directament al soll. Carotes, raves, espinacs.
  • Trasplantament: primer safata al viver, despres hort. Tomàquets, pebrots, alberginies.
  • Marc de plantacio: distancia entre plantes i entre files. Tomàquet 60x40 cm.
  • Dies fins a collita (DTC): tomàquet cherry uns 65 dies des de trasplantament.
  • Foto-periodicitat: hores de llum que necessita la planta per florir.
  • Vernalitzacio: periode de fred per florir (cols, pastanagues de guardar).

Taula de sembra per a Osona

Les dates son aproximades i poden variar ±2 setmanes. A Osona les gelades de primavera poden allargar-se fins a finals d'abril a la zona alta (900+ m), i les primeres gelades de tardor arriben a mitjans d'octubre.

Rotacio de cultius: la clau de la salut del soll

Si plantes tomàquets al mateix lloc cada any, el soll s'esgota, els nematodes augmenten, i les plagues s'instal·len. La rotacio de 4 anys es la mes utilitzada:

  1. Any 1: Lleguminoses (mongetes, pesols) - fixen nitrogen.
  2. Any 2: Solanacies i Cucurbitacies (tomàquet, carbasso) - aprofiten el nitrogen.
  3. Any 3: Brassicacies i Compostes (cols, enciams) - arrels diferents.
  4. Any 4: Arrels i bulbs (pastanaga, all) - tanquen el cicle.

A l'Hort Osona tenim 4 sectors. Rotem les families cada any. L'api i el fonoll son bon predecessors per a la col perque les seves arrels repel·leixen la mosca de la col.

Darrera gelada: el parametre critic

A Osona la data de darrera gelada (a 850 m) es al voltant del 15 d'abril, pero pot variar de l'1 d'abril al 10 de maig. La primera gelada de tardor sol ser a mitjans d'octubre.

Com saber la data exacta a la teva zona? Consulta les dades del teu sensor de temperatura o mira la web del Servei Meteorologic de Catalunya. Una bona regla es no plantar solanacies fins 2 setmanes despres de la darrera gelada a la teva zona.

A l'Hort Osona tenim un sensor de temperatura exterior que enregistra tot l'any. A partir de 2-3 anys de dades podem calcular la data mitjana de darrera gelada amb precisio.

Com guardar el calendari

Al BernatLab usem YAML perque es lisible per humans i es pot versionar a Git. Cada cultiu te una entrada amb les dates clau i les condicions:

# hort-osona/calendari/tomato-cherry.yaml
cultiu: tomàquet cherry
familia: solanacia
varietat: "Sungold"
durada_dies: 65
planta_per_m2: 4
temperatura_minima_germinacio: 18
temperatura_optima_germinacio: 22-28
gelada_mortal: true

sembra_interior:
  inici: 2026-02-15
  fi: 2026-03-15

trasplantament:
  inici: 2026-04-25
  fi: 2026-05-20
  condicio: gelades passades + T minima > 10°C
  marc: 60x40 cm

collita:
  inici: 2026-07-15
  fi: 2026-10-15

notes:
  - "Tutorejar amb canya des del primer moment"
  - "Tallar xupons fins al 5e pom"
  - "Mulch de palla per conservar humitat"

Per cultius de sembra directa (pastanaga, rave) nomes cal el periode de sembra i collita. Per cultius plurianuals (all, col) el calendari s'allarga mes enlla d'una temporada.

Com generar el calendari amb Python

Podem generar el calendari automaticament a partir dels fitxers YAML i les dades de temperatura:

# scripts/generar_calendari.py
import yaml
from datetime import date
from pathlib import Path

def feines_setmana(calendari_dir, avui):
    feines = []
    for fitxer in calendari_dir.glob("*.yaml"):
        cultiu = yaml.safe_load(fitxer.read_text())
        nom = cultiu["cultiu"]
        for periode, accio in [
            ("sembra_interior", "SEMBRAR EN SAFATA"),
            ("sembra_directa", "SEMBRAR DIRECTE"),
            ("trasplantament", "TRASPLANTAR"),
        ]:
            if periode in cultiu and "inici" in cultiu[periode]:
                inici = date.fromisoformat(cultiu[periode]["inici"])
                fi = date.fromisoformat(cultiu[periode]["fi"])
                if inici <= avui <= fi:
                    feines.append(f"{accio}: {nom} (fins {fi})")
    return feines

Aquest script es pot cridar cada dilluns via cron i enviar un correu o un missatge a Telegram amb les feines de la setmana. Aixi no t'oblides mai de res.

Integracio amb els sensors

El calendari nomes te sentit si llig les dades reals:

  • Risc de gelada: si el sensor de temperatura prediu <0°C a les properes 24h, avisa per plantar cobertors o entrar plantes en test.
  • Temperatura del soll: nomes trasplantar tomàquets si la T del soll es >12°C de mitjana a 10 cm.
  • Humitat del soll: decidir si cal regar en funcio de la previsio de pluja i la humitat actual.
  • Dies graus (GDD): calcular la integral termica per predir quan madura un fruit.

Plantilles mensuals

Cada mes te les seves feines tipiques:

  • Gener-Febrer: planificar temporada, comprar llavors, preparar safates, sembrar tomàquets al viver.
  • Març: trasplantar enciams primerencs, sembrar pastanagues i raves, adobar amb compost.
  • Abril: vigilar gelades tardanes, trasplantar tomàquets al final, sembrar mongetes.
  • Maig: trasplantar pebrots, sembrar carbassons, instal·lar tutors, primers regs.
  • Juny: aclarir pastanagues, collir primers enciams, plantar carbassons, vigilar pugons.
  • Juliol: reg abundant, collir tomàquets, sembrar cols de tardor.
  • Agost: collita forta, sembrar espinacs, plantar cebes d'hivern.
  • Setembre: plantar alls, sembrar enciams d'hivern, collir carbasses.
  • Octubre: collir ultimes tomàquets, tapar compost, retirar canyes.
  • Novembre-Desembre: arranjar eines, planificacio, repòs del soll.

🛠️ Exercici pràctic (45-60 min)

Crear un calendari de sembra complet per a l'Hort Osona amb 8-10 cultius principals, en format YAML. El calendari ha de cobrir tot l'any i ha d'incloure la rotacio de 4 sectors. Acabarem generant les feines de la setmana amb un script Python.

Pas 1: Estructura de carpetes (5 min)

mkdir -p ~/hort-osona/calendari
cd ~/hort-osona/calendari
touch tomato-cherry.yaml pebrot-italia.yaml \
      enciam-meravella.yaml pastanaga-nantes.yaml \
      mongeta-tendres.yaml carbasso-butternut.yaml \
      col-de-brusel·les.yaml all-violeta.yaml

Pas 2: Definir 3 cultius d'estiu (15 min)

Crea tomato-cherry.yaml amb familia, durada_dies, planta_per_m2, temperatures, sembra_interior (inici/fi), trasplantament (inici/fi/condicio/marc), collita (inici/fi), i notes. Repeteix amb pebrot-italia i carbasso-butternut.

Pas 3: Definir 3 cultius de primavera/tardor (10 min)

Crea enciam-meravella.yaml amb sembra cada 2 setmanes per collita esglaonada. Afegeix tambe pastanaga-nantes i mongeta-tendres.

Pas 4: Definir 2 cultius d'hivern (10 min)

Crea all-violeta.yaml amb sembra octubre-gener, collita juny-juliol (necessita vernalitzacio). Afegeix col-de-brusel·les amb sembra juny, trasplantament agost, collita octubre-desembre.

Pas 5: Definir la rotacio de 4 sectors (10 min)

Crea rotacio-sectors.yaml amb 4 sectors (A, B, C, D), cadascun amb un id, superficie, ubicacio, i rotacio de 4 anys (lleguminosa -> solanacia -> brassicacia -> arrel).

Pas 6: Script per generar les feines (10 min)

Crea ~/hort-osona/scripts/generar_calendari.py que carregui tots els YAML, comprovi les dates de sembra_interior, sembra_directa, trasplantament i collita, i retorni les feines del dia. Inclou gestio d'errors amb try/except.

Pas 7: Provar-ho (5 min)

cd ~/hort-osona
python3 scripts/generar_calendari.py ./calendari

Hauries de veure les feines que toquen avui segons el calendari. Prova tambe amb una data especifica passant-la com a parametre.

Pas 8: Integracio amb cron (5 min)

Crea un script setmanal.sh que cada dilluns al mati (cron 0 7 * * 1) enviï un correo amb les feines de la setmana.
