📖 Resum del capítol

La idea clau

El Xiaomi MiFlora (HHCCJCY10) es un sensor bluetooth que es clava al test i et diu si la planta te set, te calor, te nutrients i te llum. Es petit (~5 cm), te pila de botó que dura un any, i val uns 10-15€. Es el sensor favorit dels horts urbans perque es no-invasiu (no cal cablejat) i barat (10 plantes = 100€).

Que es el MiFlora i que mesura

El sensor es un tub de plastic blanc amb quatre sensors dins i una pila CR2032. Emet per BLE cada 5-10 min amb quatre lectures:

  • Soil moisture (%) - humitat del substrat
  • Soil temperature (°C) - temperatura del soll
  • EC / Fertility (µS/cm) - conductivitat, proxy de nutrients
  • Light (lux) - lluminositat

A mes: nivell de bateria i temps desde l'ultim reset.

Per que BLE i no WiFi o Zigbee

El MiFlora usa Bluetooth Low Energy (BLE) per raons d'estalvi energetic. La pila CR2032 aguanta un any transmetent cada pocs minuts. Si fos WiFi, la pila duraria dies. L'inconvenient es que la RPi ha d'estar a prop (10-20 metres).

Integracio a la RPi

La llibreria Python miflora combinada amb paho-mqtt es la solucio mes utilitzada:

pip install miflora paho-mqtt

Script minim que llegeix i publica a MQTT:

from miflora.miflora_poller import MiFloraPoller
from btlewrap.bluepy import BluepyBackend
import paho.mqtt.client as mqtt
import json

poller = MiFloraPoller(mac="C4:7C:8D:65:1B:32", backend=BluepyBackend)
moisture, temp, ec, light, battery = poller.parameter_value(MiFloraPoller.SERVICE_DATA)

client = mqtt.Client("miflora-gateway")
client.connect("localhost", 1883)
client.publish("hort-osona/miflora/1B32",
               json.dumps({"moisture": moisture, "temp": temp}),
               qos=1)

Decodificacio del advertisement BLE

El MiFlora envia un "service data" amb un format propietari Xiaomi. La llibreria miflora ja el descodifica. Format v3+: firma (1B) + seq (2B) + moisture (1B) + temp (2B signed LE) + EC (2B unsigned LE) + light (4B uint32 LE) + battery (1B).

Bona praxis i limitacions

  • No submergir en aigua; treure abans de trasplantar; canviar pila cada any.
  • Alcance limitat 10-20 m; lent per arrancar (2-3 s); no apte per sòl argilós; no te datalogger intern.

🛠️ Exercici pràctic (30-45 min)

Connectar un sensor MiFlora a la RPi, llegir les seves dades cada 15 min i publicar-les a un broker MQTT.

Pas 1: Verifica el Bluetooth (5 min)

sudo apt install bluetooth bluez bluez-tools
sudo systemctl status bluetooth
sudo hcitool lescan

Apunta la MAC del teu MiFlora: C4:7C:8D:xx:xx:xx.

Pas 2: Instal·la les dependencies (5 min)

mkdir -p ~/hort-osona/services/miflora
cd ~/hort-osona/services/miflora
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install miflora paho-mqtt pyyaml

Pas 3: Primer test del sensor (10 min)

sudo python3 test_miflora.py C4:7C:8D:65:1B:32

Sortida esperada: humitat, temperatura, EC, llum i bateria.

Pas 4: Crea el servei continu (15 min)

Crea miflora_service.py amb el bucle de 15 min que publica a MQTT, i config.yaml amb les MACs i credencials del broker.

Pas 5: Prova el servei (5 min)

source .venv/bin/activate
sudo python3 miflora_service.py
mosquitto_sub -h localhost -t "hort-osona/miflora/#" -v

Pas 6: Fer-lo correr com a dimoni (5 min)

Crea /etc/systemd/system/hort-miflora.service amb Type=simple, Restart=on-failure i WantedBy=multi-user.target. Activa'l amb systemctl enable.

Validació

  • ☐ Has descobert la MAC amb hcitool lescan.
  • ☐ Has llegit el sensor amb test_miflora.py.
  • ☐ El servei publica cada 15 min a MQTT.
  • ☐ Has vist els missatges amb mosquitto_sub.
  • ☐ El servei systemd esta actiu.
