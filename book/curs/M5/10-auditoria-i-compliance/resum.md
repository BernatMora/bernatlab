# Resum - Capitol 10: Auditoria i compliance

## La idea clau

Un cop tens el sistema configurat, cal verificar periodicament que **tot segueix correcte**: contrasenyes, configuracio, logs, etc.

## Que es una auditoria?

- Revisio periodica del sistema.
- Verificar compliment de politiques.
- Detectar desviacions.

## GDPR i altres normatives

Si tractes dades personals (noms, emails, etc.), sha de complir el GDPR.
- Consentiment explicit.
- Dret a loblit.
- Minimitzacio de dades.
- Seguretat adequada.

## Checklist dauditoria

- [ ] Contrasenyes uniques per a cada servei.
- [ ] 2FA activat on sigui possible.
- [ ] Certificats TLS actualitzats.
- [ ] Backups funcionant.
- [ ] Logs rotant.
- [ ] Usuaris inactius eliminats.
- [ ] Ports minims oberts.
- [ ] Sistema actualitzat.

## Eines dauditoria

- **Lynis**: auditoria de seguretat de Linux.
- **OpenVAS**: scanner de vulnerabilitats.
- **Nessus**: comercial.

## Frequencia

- **Setmanal**: revision rapida (logs, serveis actius).
- **Mensual**: auditoria completa.
- **Trimestral**: revisio de compliment.

## Documentacio

Cada auditoria sha de deixar un registre: data, troballes, accions.
