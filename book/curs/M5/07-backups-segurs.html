📖 Resum del capítol

La idea clau

Un backup no es un luxe, es la diferencia entre un incident i una catastrofe. Pero un backup nomes es valid si es pot restaurar. I nomes es segur si esta xifrat i fora del servidor. Al BernatLab farem servir Restic: una eina moderna que fa copies incrementals, xifrades, deduplicades, i que es pot enviar a multiples destins (local, S3, SFTP, B2, etc.).

La regla 3-2-1

La regla d'or dels backups:

  • 3 copies de les dades (l'original + 2 backups).
  • 2 tipus de mitjans diferents (disc local + núvol).
  • 1 copia fora de casa (cloud, casa d'un amic, etc.).

Aquesta regla ens protegeix contra fallada de hardware, errors humans, ransomware, catastrofes naturals, i robatori.

Que cal backupejar al BernatLab

  • Bases de dades: Postgres, InfluxDB, SQLite, MariaDB.
  • Volums Docker: carpetes /var/lib/docker/volumes/....
  • Configuracions: /etc/nginx, /opt/*/docker-compose.yml, .env.
  • Secrets (xifrats!): claus SSH, configuracio de Tailscale.
  • Dades personals: documents, fotos, configuracio de Home Assistant.
  • Repositoris Git locals: Gitea, etc.

Restic: l'eina que recomano

Restic es una eina de backup moderna i senzilla:

  • Xifratge: AES-256, autenticacio amb contrasenya o fitxer de claus.
  • Incremental: nomes copia el que ha canviat.
  • Deduplicacio: si un fitxer esta en diversos llocs, no el duplica.
  • Multi-desti: local, S3, SFTP, Backblaze B2, etc.
  • Open source: llicencia BSD.
sudo apt install restic

Primer backup amb Restic

# Inicialitza un repositori
export RESTIC_REPOSITORY=/var/backups/homelab
export RESTIC_PASSWORD="una_contrasenya_llarga_i_aleatoria"
restic init

# Fes la primera copia
restic backup /opt/homelab /opt/gitea /etc/nginx

# Comprova
restic snapshots
restic stats

# Restaura
restic restore latest --target /tmp/restore

Guarda la RESTIC_PASSWORD al vault (capitol 6). Si la perds, no podràs restaurar mai.

Restic amb un desti remot

# SFTP
export RESTIC_REPOSITORY=sftp:user@backup.bernatlab.cat:/backups/restic

# S3 (AWS, Minio, Backblaze B2)
export RESTIC_REPOSITORY=s3:s3.amazonaws.com/bernatlab-backup

Backends suportats: local, sftp, s3, b2, azure, gs, rclone.

Politica de retencio

restic forget \
  --keep-hourly 24 \
  --keep-daily 7 \
  --keep-weekly 4 \
  --keep-monthly 6 \
  --prune

Mantindra 24 hores, 7 dies, 4 setmanes, 6 mesos. Esborra les mes antigues.

Automatitzacio amb cron o systemd

Script d'exemple /opt/homelab/scripts/backup.sh:

#!/bin/bash
set -e
set -a
source /opt/homelab/.env
set +a

restic backup /opt/homelab /opt/gitea /etc/nginx
restic forget --keep-hourly 24 --keep-daily 7 --keep-weekly 4 --keep-monthly 6 --prune

Cron:

0 3 * * * /opt/homelab/scripts/backup.sh >> /var/log/backup.log 2>&

Systemd (mes net):

# /etc/systemd/system/backup.timer
[Timer]
OnCalendar=*-*-* 03:00:00
Persistent=true

Bones practiques

  • Automatitza SEMPRE. No confiïs en la memoria.
  • Monitora els backups: correu o webhook si fallen.
  • Prova la restauracio periodicament (cada 3-6 mesos).
  • Xifratge obligatori.
  • Multiples destins: local + núvol.
  • Custodia de la clau: si la perds, no pots recuperar res.
  • Documenta la politica de retencio.
  • Audita la mida: creixement sobtat = possible problema.

Proves de restauracio

Un backup no es valid fins que no l'has restaurat. Crea un entorn de test:

mkdir -p /tmp/restore-test
restic restore latest --target /tmp/restore-test
ls -la /tmp/restore-test/opt/homelab/
rm -rf /tmp/restore-test

Comandes utils

# Llistar snapshots
restic snapshots

# Veure fitxers d'un snapshot
restic ls latest

# Estadistiques
restic stats

# Restaurar
restic restore latest --target /tmp/restore

# Esborrar antics
restic forget --keep-daily 7 --prune

# Comprovar integritat
restic check

# Mount (navegar el backup)
mkdir /mnt/restic
restic mount /mnt/restic
fusermount -u /mnt/restic

Conclusio

Els backups son la xarxa de seguretat que et permet dormir tranquil. Restic + bona politica de retencio + automatitzacio + proves de restauracio es el minim per estar protegit. Recorda: un backup no es un backup fins que no l'has restaurat amb exit.

🛠️ Exercici pràctic (30-45 min)

Configurar Restic per fer backups automatics del BernatLab amb una politica de retencio, un desti extern, i una prova de restauracio.

Pas 1: Inventaria que cal backupejar (5 min)

ls -la /opt
ls -la /var/lib/docker/volumes/
docker ps --format '{{.Names}}:{{.Image}}'

Pas 2: Instal·la Restic (5 min)

sudo apt install restic
restic version

Pas 3: Inicialitza el repositori (10 min)

sudo mkdir -p /var/backups/homelab
sudo chown bernat:bernat /var/backups/homelab

export RESTIC_PASSWORD=$(openssl rand -base64 32)
echo "Guarda aquesta clau al vault: $RESTIC_PASSWORD"
export RESTIC_REPOSITORY=/var/backups/homelab
restic init

Pas 4: Fes el primer backup (5 min)

restic backup /opt/homelab /opt/gitea /etc/nginx
restic snapshots
restic stats

Pas 5: Politica de retencio (5 min)

restic forget --keep-hourly 24 --keep-daily 7 --keep-weekly 4 --keep-monthly 6 --prune

Pas 6: Script d'automatitzacio (10 min)

#!/bin/bash
set -e
set -a
source /opt/homelab/.env
set +a

restic backup /opt/homelab /opt/gitea /etc/nginx
restic forget --keep-hourly 24 --keep-daily 7 --keep-weekly 4 --keep-monthly 6 --prune

Pas 7: Cron o systemd (5 min)

echo "0 3 * * * /opt/homelab/scripts/backup.sh >> /var/log/backup.log 2>&1" | sudo tee /etc/cron.d/backup

Pas 8: Nuvol (opcional) (5 min)

export RESTIC_REPOSITORY=s3:s3.eu-central-003.backblazeb2.com/bernatlab-backup
restic init
restic backup /opt/homelab

Pas 9: Prova la restauracio (5 min)

mkdir -p /tmp/restore-test
restic restore latest --target /tmp/restore-test
ls -la /tmp/restore-test/opt/homelab/
rm -rf /tmp/restore-test

Validació

  • ☐ Restic esta instal·lat.
  • ☐ Has inicialitzat un repositori.
  • ☐ Has fet un primer backup.
  • ☐ La politica de retencio esta configurada.
  • ☐ El backup esta automatitzat.
  • ☐ Has provat la restauracio amb exit.
