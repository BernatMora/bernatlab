2. Arquitectura de l'Hort (IoT)

Sensors LoRa 868 MHz MQTT InfluxDB Grafana

El viatge d'una lectura des del test de tomàquets fins a la gràfica de Grafana: el sensor MiFlora es comunica amb el mòdul SX1262 per ràdio LoRa a 868 MHz, el gateway (RPi) el passa a un broker MQTT, Telegraf el desa a InfluxDB, i Grafana + Node-RED el visualitzen i l'envien a la web pública d'Hort Osona.
