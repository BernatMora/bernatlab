# Idees - Creatius i experimentals

> Projectes ludics, creatius o experimentals. Sense un objectiu practic clar, pero divertits i educatius.

## Idees

### Generador de patrons NeoPixel en un aro

- **Dificultat**: Mitjana
- **Cost**: ~20 EUR
- **Temps**: 4-5 h
- **Components**: ESP32 + tira de LEDs WS2812B (60 LEDs) + bateria
- **Utilitat real**: Aro de llums que mostra patrons animats.
- **Coneixements**: NeoPixels, PWM, patrons, colors.
- **Integracio**: Es pot controlar via Bluetooth des dun mobil.

### Joc de destresa amb LEDs i polsador

- **Dificultat**: Mitjana
- **Cost**: ~15 EUR
- **Temps**: 3-4 h
- **Components**: ESP32 + 4 LEDs + 4 polsadors + buzzer
- **Utilitat real**: Joc tipus "Simon" amb patrons aleatoris.
- **Coneixements**: Aleatorietat, timers, audio basic, logica de joc.
- **Integracio**: Es pot extendre amb mes dificultats.

### Termometre artistic amb NeoPixels

- **Dificultat**: Mitjana
- **Cost**: ~20 EUR
- **Temps**: 4-5 h
- **Components**: ESP32 + tira de LEDs WS2812B + sensor de temperatura
- **Utilitat real**: Tira de LEDs que canvia de color segons la temperatura.
- **Coneixements**: NeoPixels, sensors, colors, PWM.
- **Integracio**: Es pot fer reactiu a qualsevol sensor.

### Rellotge binari amb LEDs

- **Dificultat**: Mitjana
- **Cost**: ~15 EUR
- **Temps**: 3-4 h
- **Components**: ESP32 + 4 LEDs + Wi-Fi (NTP)
- **Utilitat real**: Rellotge que mostra lhora en binari.
- **Coneixements**: NTP, binari, timers, Wi-Fi.
- **Integracio**: Es pot millorar amb una pantalla.

### Controlador de garatge per a joguines

- **Dificultat**: Baixa
- **Cost**: ~15 EUR
- **Temps**: 2-3 h
- **Components**: ESP32 + servo + polsador + bateria
- **Utilitat real**: Obre i tanca la porta dun garatge de joguines.
- **Coneixements**: Servos, PWM, mecanica basica.
- **Integracio**: Es pot controlar via Wi-Fi.

### Drac mini amb 4 servos

- **Dificultat**: Alta
- **Cost**: ~30 EUR
- **Temps**: 10-12 h
- **Components**: ESP32 + 4 servos + estructura impresa en 3D + bateria
- **Utilitat real**: Un petit drac de 4 potes que camina.
- **Coneixements**: Servos, mecanica, cinemàtica inversa basica.
- **Integracio**: Es pot controlar via Bluetooth o Wi-Fi.

### Sensor de mentides basic amb GSR

- **Dificultat**: Mitjana
- **Cost**: ~25 EUR
- **Temps**: 4-5 h
- **Components**: ESP32 + sensor GSR (resistencia de la pell) + pantalla OLED
- **Utilitat real**: Mesurar la conductivitat de la pell per veure si estas nerviós.
- **Coneixements**: Sensors analogics, ADC, calibratge, biofeedback.
- **Integracio**: Es pot desar les dades a una SD.

### Aura visual amb tira de LEDs

- **Dificultat**: Mitjana
- **Cost**: ~20 EUR
- **Temps**: 4-5 h
- **Components**: ESP32 + tira de LEDs + sensor de so
- **Utilitat real**: Tira de LEDs que reacciona al so ambient.
- **Coneixements**: Sensors de so, FFT basica, NeoPixels, processament de senyal.
- **Integracio**: Es pot combinar amb un sistema audio mes gran.
